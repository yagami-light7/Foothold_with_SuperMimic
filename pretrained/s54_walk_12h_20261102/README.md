## 服务器使用

当前保留的`scripts/train_walk_retention_12h.sh`默认加载本目录模型，支持`--checkpoint FILE`覆盖。其课程仍是直行，没有yaw-rate转向命令。启动前需把训练启动器的Isaac Lab解释器路径调整为服务器实际路径；本次没有改动服务器环境配置或自动启动训练。

已验证软件快照：Python3.12.15、Isaac Lab目录IsaacLab_3_0（distribution27.2.0）、Newton1.6.1、Warp1.17.0、RSL-RL5.5.1、PyTorch2.11.0+cu130。3090服务器需要使用与自身驱动兼容的Isaac Lab/CUDA环境；不复制本地虚拟环境。

## 后续任务顺序

按用户选择，先学左右转弯、边走边绕圈，之后再加原地转圈。当前代码的参考朝向在reset时固定，角速度奖励目标为0；直接继续现有命令不会自动得到可控转圈策略。

后续需要：

1. 将目标角速度或目标航向变化编码进可见Goal/Observation；更新足印位置和Yaw，使其跟随转向参考。
2. 将角速度奖励改为跟随指令，配合转向参考航向；保留支撑、防滑、防跳约束。
3. 先在较容易的步长/频率学习双向弧线，同时回放直行；再拓展大小步、动态频率切换，最后加入原地转向。
4. 若新增观测维度，需要扩展现有105维checkpoint迁移与训练/eval契约；现有迁移器只支持103/104/105，不可直接假设新维度兼容。

这部分是后续训练设计，尚未实现或验证；本目录只提供已经验证的直行权重和元数据。
