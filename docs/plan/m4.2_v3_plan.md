# M4.2 v3 实施计划

1. 核对正式训练日志、检查点轮次及实际运行配置。先审计真实 Reward、Termination、独立评估和落脚判定。
2. 用现有冻结权重从相同 F2 起点运行 Newton，记录每步状态、接触、奖励、目标及裁剪，生成一份并排视频和一份数值轨迹。
3. 用同一批真实轨迹验证 Critic 输入、真实回报校准和 Actor 梯度分解。对照 WM 的短时预测与 Newton，并按支撑状态、动作裁剪和速度分组。
4. 根据前述证据选择最小训练改动，和匹配的对照组比较步态、误差和存活。保持 v2 输出，实验只运行短预算。
5. 在 `docs/report/m4.2_v3_report.md` 记录证据、检查点缺口、结果及下一阶段建议，清理临时实验文件。
