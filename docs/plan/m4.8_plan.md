# M4.8 启动过渡与上身平滑消融计划

以 M4.3 Best 为四步基线，检验从头训练能否适应上身 0.20 s Smoothstep，以及原始动作二阶差分正则能否改善连续行走的平滑性。M4.7 的冻结策略结果与本轮 Fresh Start 结果各自记录。[任务说明](../prompt/m4.8.md) · [M4.7 启动诊断](../report/m4.7_report.md)

| --- | ---: | ---: | ---: |
| M4.3 基线 | 关闭 | 0 | 0 |
| M4.8-A | 0.20 s | 0 | 0 |
| M4.8-B | 关闭 | 0.02 | 0 |
| M4.8-C | 0.20 s | 0.02 | 0 |

## 训练与检查

1. 复用 Roban 21-DoF 和原 F2，保留 50 Hz 控制、Newton 8×2.5 ms、Hard Clamp 和 M4.3 Swing-Aware Reward。三组均为 seed 0、256 环境、5000 轮，前 1000 轮为 WM-only。核对有效配置、Initial 张量及空优化器状态。[启动器](../../tools/run_m48_ablation.sh)
2. 上身过渡执行端从实际 Reset 姿态过渡到 Hard Clamp 目标。Replay 和 WM 使用等效执行动作，BPTT 恢复同一 Reset 姿态、步龄和前两步 Raw Action。以 37 项回归和隔离 CUDA Smoke 核对奖励、观测、时间梯度及异步 Reset。[回归入口](../../tools/test_m47_controls.py)
3. 审计每 500 轮的名义评估、三组 Best 与 Last、训练损失和故障记录。Best 以完整四步、首落、连续落脚及存活优先排序，保留训练时的选择结果供独立复评。[验收报告](../report/m4.8_report.md)

## 训练后验收

1. 冻结 M4.3 Best 4500 和 M4.8 三组各自 Best、Last，统一使用原 CUDA Newton 镜像。每份权重闭环执行 3 条名义轨迹（1001–1003）和 6 条组合扰动轨迹（1101–1106）。同种子起态配对，沿用原落脚、连续承重和终止判定。
2. 每份权重和种子都记录起步 0.24 s 的 400 Hz 子步数据。对 `[0, 0.20)` s 右肘有限差分加速度取峰值，单独查看 0.20 s 过渡交界后的 40 ms，并报告首个 20 ms 的 PD 目标误差、速度、平均加速度和力矩饱和。
3. 按种子对齐 0.20 s 之后的共同观测区间，统计九关节速度、加速度、jerk、Raw/Effective Action 和实际 PD Target 二阶差分，以及双臂 8–25 Hz 绝对功率及占比。以双手相对躯干的前后摆幅、左右相位关联、肘角范围和近限位比例描述上身运动。
4. 以名义完整四步 3/3、扰动完整四步至少 4/6、扰动首落和存活尽量达到 6/6 为步态对照。启动峰值下降约 50%、持续平滑性指标下降约 30% 是工程目标。按 Best、Last、名义和扰动分别记录实际达成情况及失败种子，保留一份可复算归档。

## 后续核验

1. 以 M4.3 Best 作默认对照，使用 C Best 检查 1101 的首落时序与 1104 的第二步连续承重。同步分析躯干、摆动脚与接触力，定位同批扰动中失配的阶段。
2. 以 B Best 作仅平滑对照。针对 B Best 右肘伸直端和 C Best 双肘相反端的长时间近限位，按实际角度、下发目标与实测约束力核对。后续候选的自然性验收同时看近限位比例、双手摆幅和相位。
3. 如扩大训练，优先复核 C 的组合收益是否跨训练种子和动作片段保持，并继续把完整步态、首落、连续承重与存活作为检查点选择依据。[实测结果](../report/m4.8_report.md) · [训练后评估入口](../../supermimic/integration/m48_evaluation.py)
