# M4.3 实施计划

1. 对照 M4.2 v3 实测接触和 F2 足底几何，验证长尾位置、相位高度、承重代理和落脚窗的梯度。通过单元测试和 Newton 冒烟后冻结奖励配置。
2. 用种子 0、256 世界、`2e-4` Actor 学习率全新训练 5000 轮。保持 F2、模型和物理契约，保存阶段检查点、一个训练 CSV 和异常快照。按阶段独立评估，用步态优先级选权重。
3. 在固定公共样本和各阶段策略真实轨迹上检查 WM 的 1/4/8 步预测、有限差分方向和 BPTT 梯度。对照旧、新奖励下同一对动作扰动。
4. 用统一的 F2 起态、种子及评估器对照基线、最终及最佳策略。保留必要视频、曲线、数值轨迹和诊断数据，交付 `docs/report/m4.3_report.md`。
