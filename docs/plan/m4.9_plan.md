# M4.9 长程训练与姿态先验消融计划

用 10000 轮 Fresh Start 对照训练预算和姿态先验。A 仅延长 M4.8-C 的预算，B 加原 Body Prior 0.02，C 加 Soft Body Prior 0.02。三组共同使用 0.20 s 上身启动过渡、平滑权重 0.02、Roban F2 和 Hard Clamp。[任务说明](../prompt/m4.9.md) · [M4.8 基线](../report/m4.8_report.md)

## 训练与核对

1. 从相同 seed 0 初始化 Actor、WM 和 Critic，256 环境，前 1000 轮仅更新 WM。核对实际 Initial、空 Adam 和基线设置。学习率由绝对轮次和 250000 轮衰减周期决定，前 5000 轮的学习率、更新和探索配置与 M4.8-C 一致。
2. 用历史冻结轨迹和 16 步 BPTT 标定 C 组。按左右对称的具名映射，六个肩部关节取 0.35 rad、双肘 0.25 rad、腰偏航 0.20 rad。用匹配状态的 Newton 分支检查饱和区和合法区的真实变化。[标定数据](../../outputs/m4_9/prior_calibration/results.json)
3. 每 500 轮做三种子轻量评估并保存里程碑。Best 依次按存活、完整和连续落脚、首落、足与根跟踪，再考虑姿态及平滑性。用 5000–10000 轮的多个周期点判断恢复、回退与姿态演化。[训练启动器](../../tools/run_m49_ablation.sh)

## 统一复评

1. 冻结 A/B/C 的 5000、Best 和 10000 轮。额外取 C 组后半程名义 3/3 的检查点中，双肘较差一侧近限位比例最低的权重。用相同物理和数据契约下的 M4.3 Best、M4.8-C Best/Last 归档作历史对照。
2. 使用 CUDA Newton 对每份新权重做 1001–1003 名义回放和 1101–1106 组合 Reset 扰动。对照首次摆腿、首次落脚、连续承重、完整四步、存活、足与根误差和物理安全计数。起步另读 400 Hz 子步，覆盖首步、0–0.20 s 以及过渡结束后的 0.20–0.24 s。
3. 同时统计各权重共同的有效窗口，以及完整四步成功轨迹的全持续段。汇报上身角速度、加速度、jerk、Raw/Effective Action 与实际 PD 目标二阶差分。比较臂腰参考误差、肘角、近限位比例、双手摆幅与同侧摆腿关联。成功轨迹的趋势也用与 M4.8-C Best 通过同样种子的子集核对。
4. 工程验收以名义 3/3、扰动至少 4/6、首落尽量 6/6、存活 6/6 为步态目标，同时检查双肘近限位比例是否低于 20%。用 M4.8-C Best 的启动峰值、持续段加速度、jerk 和实际目标二阶差分核对平滑性。[复评代码](../../supermimic/integration/m49_evaluation.py) · [结果报告](../report/m4.9_report.md)

## 后续验证

1. 保留 M4.8-C Best 作为控制基线，冻结 A9000、C8500 和 C9500 作为对照。先复查 0–1.6 s 的支撑转换。重点核对 C8500 六条扰动的首次卸载失败，以及 C9500 种子 1101 通过、1102/1103/1105 首落前后因根高或倾斜终止的分歧。用同种子轨迹对齐根高、倾角、双足接触力与左踝目标。按根姿态、关节初角和初速度分别施加 Reset 扰动，检验哪类输入先破坏首摆和落脚。
2. 后续候选在多个周期点做同一组扰动回放，以名义 3/3、扰动四步至少 4/6 和存活 6/6 作为选权重的前置条件。达到步态门槛后再比较双肘近限位、完整段平滑性与过渡结束后的冲击。
3. 对通过门槛的方案补训练种子和独立动作参考，确认低近限位、启动减冲击和完整步态能在同一权重上复现。[现有闭环及子步轨迹](../../outputs/m4_9/cuda_evaluation.npz)
