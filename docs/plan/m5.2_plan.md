## 奖励与分组

实际和参考各自去航向后的单位竖直轴为 `u` 和 `u_ref`。令 `e = 0.5 × ‖u − u_ref‖²`、`T = exp(−e / 0.03)`、`U = exp(−(1 − R_zz) / 0.10)`。新增项采用当前步后参考的质量 `Q`，Upright 沿用原计算方式。局部 X 接近竖直时用局部 Y 的水平投影推定航向。新增项在统一 Reward 路径应用各一次权重、质量门与 0.02 s 时步。其他奖励逐项核对为源 C1500 配置，三组正奖励归一化分母均为 0.101。[姿态数学](../../supermimic/integration/m52_orientation.py) · [任务配置与继承契约](../../supermimic/integration/m52_task.py)

| 组 | 单步姿态贡献 | 生效配置 |
| --- | --- | --- |
| A | `0.02 × 0.50U` | [m5_2_a.json](../../configs/roban/m5/m5_2_a.json) |
| B | `0.02 × [0.50U + 0.50Q(T − 1)]` | [m5_2_b.json](../../configs/roban/m5/m5_2_b.json) |
| C | `0.02 × 0.50QT` | [m5_2_c.json](../../configs/roban/m5/m5_2_c.json) |

45 条真实 Replay 上 A 与原奖励逐值相同。C1500 状态在固定 Sigma 下的平均 `T` 为 0.547–0.553。用已记录动作推进 WM，Tilt 预测 RMSE 在 1/4/8/16 步分别为 0.034–0.036°、0.118–0.132°、0.245–0.278°、0.544–0.579°。16 步分项 BPTT 的 Tilt Actor 梯度范数为 0.485–1.151，Tilt 与 Upright 的余弦跨 −0.894 至 +0.352，Bootstrap/Tilt 范数比为 0.203–0.917。固定参数与现有 Bootstrap 用于正式消融。[逐片段 WM 和分阶段梯度](../../outputs/m5_2/preflight.json)

## 训练后的独立复评与选模

每 250 联合轮存权重，每 500 轮用 1001–1003 做独立 Newton 复跑。终评从各组周期候选和 2000 轮权重中选模，使用正常种子和 1101–1106 共用偏差。历史回归包含 1201–1206 留出偏差及 H1–H4 的正常和共用偏差。另预锁定 1301–1306 用于入选后 H1–H4 的新偏差试次。沿用 M5.1 的四步、存活和落脚各项判据，失败样本的误差按同片段、同种子的共同有效窗复算。[独立评估入口](../../supermimic/integration/m52_evaluation.py)

优先比较完整任务与恢复，随后核对足部姿态、实际承重和滑动，再看 Root Tilt、胸部、手肘世界空间姿态与平滑性。训练结束后用同种子原速四视角视频检查前倾、侧倾、腰髋转动、摆臂及接触。最终选定的 M5.2 与 C1500 使用同一 M3.13 R2 在线参考跑 F1/F2/F3 短段、30 s 和 60 s 固定步态以及 60 s 变参数直走。闭环表现、剩余局部误差及在线回归共同决定是否冻结 Reward。结果汇入 `docs/report/m5.2_report.md`。[视频入口](../../supermimic/integration/m52_visuals.py) · [在线回归入口](../../supermimic/integration/m52_online.py)

```bash
bash tools/run_m52_training.sh evaluate
bash tools/run_m52_training.sh visuals
bash tools/run_m52_training.sh online
```

在线回归默认使用终评排序中的首个 M5.2 模型，也可通过 `--checkpoint` 指定已选定的权重。
