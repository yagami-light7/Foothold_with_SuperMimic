# M4.11 Roban 双手末端跟踪微调计划

以 M4.10-C9000 为共同起点，检验躯干局部双手位置惩罚能否改善收臂、屈肘和摆臂，同时达到原 F2 的足步、根部跟踪和恢复指标。当前请求引用 M4.10 文件名，但交付名称及实验衔接指向 M4.11，本轮采用 M4.11 的实验设计。[任务说明](../prompt/m4.11.md) · [M4.10 结果](../report/m4.10_report.md)

## 训练前验证

1. 复用同一套可微 FK 计算 `base_link` 坐标系下左右 `handball` 刚体原点。用 F2 与真实 C9000 轨迹对照独立 MuJoCo FK，核对整体刚体变换不变性、左右手索引、奖励边界与质量门控。
2. 重计分六份历史权重的名义和偏差轨迹。比较各阶段手部误差和惩罚，并从 C9000 真实起点审计 16 步 BPTT。报告 Foot、Root、关节 Huber、手部 Huber、平滑项和 Bootstrap 的梯度强度及方向。
3. 对两组分别运行隔离 CUDA Smoke。检查加载与冻结、真实和 Replay 奖励、异步 Reset、WM 的执行动作输入、Critic 目标和联合更新。验证从预热检查点恢复以及名义周期评估入口。实测写入同一份报告。[M4.11 报告](../report/m4.11_report.md)

## 正式微调

| 组别 | 奖励 | Critic-only | 联合微调 |
| --- | --- | ---: | ---: |
| A | M4.10-C | 200 轮 | 2000 轮 |
| B | M4.10-C 加双手位置 Huber，权重 0.10、容许误差 30 mm、尺度 100 mm | 200 轮 | 2000 轮 |

两组分别载入 C9000 的 Actor、WM、Critic 及归一化器，以新 Adam 和新 Replay 起步。预热时冻结 Actor、WM 及其归一化器，由同一 seed 0 的冻结 Actor 采集，各组用自身奖励更新 Critic。联合阶段以 256 个环境、16 步想象和固定 Actor LR `5e-5` 执行。WM 和 Critic 采用共同的 `2e-4` 基础学习率及联合阶段原有本地调度。控制仍为 Hard Clamp、0.20 s 启动过渡、20 ms 控制周期以及 8 个物理子步。[A 配置](../../configs/roban/m4_11_a.json) · [B 配置](../../configs/roban/m4_11_b.json)

```bash
bash tools/run_m411_ablation.sh start
```

启动器用容器内 tmux 串行运行 A、B，配合宿主休眠抑制。每个实验保留实际生效配置、一份训练指标 CSV、一份运行日志及必要检查点。每 250 联合轮做一次名义评估并保存检查点。足步优先选择 `best_foot.pt`，名义四步 3/3 后才参与 `best_whole_body.pt` 排序。保存 `initial.pt`、`critic_warmup.pt`、轮次权重和 `last.pt`。同组可用 `resume` 续训，补采 Replay。现有 SwanLab 同步入口可用 `--roban_m411` 读取两阶段 CSV。[同步入口](../../tools/sync_swanlab.py)

## 训练结束后复评

沿用名义种子 1001–1003、偏差种子 1101–1106 和 M4.10 四步判定。比较 A10000、C9000、M4.11 A/B Best 与 Last，以及 B 的全身候选。分开统计完整成功轨迹和提前终止轨迹，同时用共同 M4.10-C 奖励重计分。重点检查名义完整四步 3/3、偏差下至少 3/6 完成和 4/6 存活、Foot RMSE ≤10 mm、Root XY/Z ≤50/30 mm、航向 ≤5°。

双手位置争取各 ≤50 mm，上臂方向误差争取各 ≤15°，并检查上身加速度 RMS ≤30 rad/s²、jerk RMS ≤2000 rad/s³、双臂高频功率和踝/肘限位。将这些结果与 WM 八步预测、Critic Bootstrap 和共同奖励差距一并评估，再生成必要的对比视频和曲线，决定能否把奖励带入 M5。
