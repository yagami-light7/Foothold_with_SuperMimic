# M4.4 实施计划

1. 用 M4.3 第 4500 和 5000 轮冻结权重重测关节目标、实际力矩、足底承重和跟踪。核对上游 SuperMimic 及已安装 Newton 的控制链。
2. 增加可配置的线性未裁剪位置目标。验证 Newton、Replay、WM、BPTT 与奖励使用一致的动作语义，确认关节机械限位和力矩限幅有效。
3. 用相同原始动作做冻结策略和零／随机／F2 对照。通过物理守卫和梯度回归后，才用 tmux 启动 5000 轮全新训练。
4. 用同一套确定性及初态扰动评估复测 M4.3 和 M4.4 的最佳及最终权重。比较真实物理表现，以及公共样本和各自策略样本的 WM 有限差分，定位左踝受限环节。
5. 保留必要的权重、训练记录、统一轨迹、视频和审计汇总。将证据、边界及建议写入 `docs/report/m4.4.md`。
