# M4.2 v2 实施计划

1. 读取正式训练的故障快照、指标与检查点，重放八个控制步。核对安装版本的 EPA 实现、接触几何与求解器缓存，记录能够复现的现象及缺少的证据。
2. 对状态检查通过且仅有 EPA 溢出的训练环境执行单环境重置。丢弃该转移并保留 Replay 序列边界，补充故障快照中的求解器状态、接触数据和复现配置，验证严重异常仍会停机。
3. 用冻结的检查点和同一组起态对照 `0.35` 与 `0.25`。分别固定动作和物理目标，统计 F2 表达范围、真实接触及动作裁剪，并对照世界模型预测与 Newton Rollout。
4. 验证动作映射及梯度、Replay 边界、Roban 的 Newton 实测和检查点短时恢复。将数据、结论和已核实的命令写入 `docs/report/m4.2_v2_report.md`，清理实验临时文件。
