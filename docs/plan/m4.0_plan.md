# M4.0 Roban F2 闭环跟踪计划

目标是在 RTX 4060 Laptop GPU 上，用 Isaac Lab 3.0 的 Newton/MJWarp 运行单条 F2 前行参考，验证 SuperMimic 的训练链路和闭环跟踪表现。

1. 核对 Roban 原始 MJCF、URDF、21 个活动关节、自由基座、腿部控制参数、资产与检查点。使用独立 M4 任务和单条只读 F2 NPZ，按时间插值，区分足底跟踪标记与物理碰撞几何，5.2 秒结束时终止。
2. 通过单环境及小批量 Headless Smoke Test 检查关节映射、有限状态、重置、关节力矩、足部接触、仿真与模型步长、Replay 奖励时间对齐以及 WM、Actor、Critic 的梯度和检查点。先运行现有 Roban 足部奖励配置 A。
3. 从头初始化网络，使用原有 Motion Encoder、Shared Decoder、World Model、Critic 和 BPTT。默认从 8 环境的 8 次迭代 Smoke 检查点恢复到 128 环境短训，先填充 Replay，再继续更新。按迭代数、时间预算和实测显存停止。根据首轮结果决定是否尝试配置 B。
4. 独立重复从 F2 起点重置，关闭探索和观测噪声。对比参考回放、初始 Actor、早期与最终检查点。统计存活时间、计划落脚匹配、根部位移与误差、足底 RMSE、接触一致性和归一化回报。按照闭环表现选最佳检查点。
5. 在 `outputs/m4_0/` 保留训练配置、关键指标、初始/早期/最佳/最终检查点和四个 MP4。在 `docs/report/m4.0_report.md` 汇总实测结果、限制以及复现命令。
