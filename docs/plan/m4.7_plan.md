# M4.7 启动冲击与上身平滑预备计划

1. 复用原 F2、Roban 和 M4.3 训练契约。冻结 M4.3 Best，先比较原始执行、等效 Reset 动作历史、0.10 s 和 0.20 s 上身过渡。另用真实物理子步骤查右肘力矩、限位和加速度，结合名义及配对扰动结果筛选方案。[M4.6 证据](../report/m4.6_report.md)
2. 用 M4.6 两个候选检查点复核有希望的方案。按首步减冲击、名义四步、扰动首落和承重验收，记录过渡末端的尖峰。训练的实际目标、Replay 有效动作和 BPTT 使用同一变换。
3. 对上身九关节原始动作使用二阶差分代价。保存同一 episode 内的两步原始动作和执行启动状态，检查 Reset 边界与时间反传。用真实 Replay 起态比较候选权重的代价量级和分相位梯度。
4. 在诊断门槛通过后准备三份 M4.3 单因素 Fresh Start 配置，检查初始化张量、日志、保存和恢复。只执行独立临时目录内的短 CUDA Smoke，覆盖 WM、Actor 与 Critic 的实际更新。
5. 交付启动诊断、权重依据和 Smoke 结果。启动方案通过后才交付串行启动与恢复命令，正式训练由用户手动启动。[预备验收报告](../report/m4.7_report.md)
