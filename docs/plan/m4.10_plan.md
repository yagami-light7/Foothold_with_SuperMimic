# M4.10 全身运动质量优化计划

以 M4.9-A 为基线，从同一 seed 0 初始化 Roban。三组分别加入 Root Tracking、Dead-zone Huber Posture Prior，以及两者叠加。保持原始 F2、足步判定、Hard Clamp、0.20 s 上身过渡和 0.02 动作平滑项。[任务说明](../prompt/m4.10.md) · [M4.9 结果](../report/m4.9_report.md)

## 训练前交付

1. 在 Newton、Replay 和 WM 共用的奖励入口实现六项奖励。Root XY、高度、航向用带死区的长尾核。肩、肘、腰逐关节计算 Huber 后取组均值，用同帧质量门控。用解析值、梯度及真实轨迹检查正奖励上界和原基线复算口径。
2. 对六份历史权重的名义和扰动轨迹重计分。取真实起点做 16 步 BPTT，按起步、单脚支撑和落脚分组测定 Foot、新项、Smoothness、Bootstrap 及总梯度。用双踝真实关节角、原始目标、限幅目标和 Newton 读回力矩定位长期裁剪。
3. 在独立临时目录各执行两轮 CUDA Smoke。核对异步 Reset、动作历史、真实与 Replay 奖励、WM 实际动作输入、有限梯度、Critic 负 Target 和周期权重别名。诊断数据集中保留在一份汇总中，Smoke 检查点随临时目录清理。[训练前报告](../report/m4.10_report.md)

## 待确认的正式训练与复评

1. 确认后用 tmux 串行执行每组 10000 轮。每 250 轮记一行训练指标，每 500 轮做名义周期评估并保存权重。Best 优先按步态和足部误差排序，全身候选须先满足名义四步 3/3，再比较 Root、上身误差和平滑性。
2. 冻结三组 5000、Best、Last 及额外全身候选，沿用名义 1001–1003、扰动 1101–1106，与 M4.3、M4.8-C、M4.9 历史对照配对。汇报名义四步 3/3、扰动四步至少 4/6、存活 6/6。跟踪目标为足 ≤25 mm、Root XY ≤50 mm、Root Z ≤30 mm、航向 ≤5°。
3. 核对肩、肘、腰和躯干局部手肘、双手几何，包括双肘近限位各 ≤10%、Arm RMSE 争取 ≤0.40 rad。共享有效窗口和完整成功轨迹均统计上身加速度、jerk、动作二阶差分、高频功率，并沿用 400 Hz 启动探针。训练完成后生成统一视角视频与必要诊断曲线。
