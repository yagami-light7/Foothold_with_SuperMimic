# M4.6 上半身先验权重消融计划

在相同 F2 任务上比较 `body_prior_weight` 为 0.00、0.02、0.05、0.10 的策略，判断较小权重能否在维持四步跟踪与扰动恢复的同时改善上身姿态。0.00 和 0.10 分别使用 M4.3 和 M4.5 的既有训练结果，0.02 和 0.05 是本轮各自从随机初始化完成的 5000 轮训练。[任务说明](../prompt/m4.6.md)

1. **核对实验契约。** 从 M4.3 配置出发逐项比较文件及有效参数，确认原 F2、Roban 21-DoF、Newton 8×2.5 ms 子步、Hard Clamp、Swing-Aware 奖励、网络和物理保护一致。两组使用 seed 0，256 环境，前 1000 轮仅更新 WM，后续按原 BPTT 与 Critic 更新规则执行。核对初始模型、归一化与空优化器状态，并记录两轮短冒烟的奖励、梯度和有效转移。[0.02 配置](../../configs/roban/m4_6_w002.json) · [0.05 配置](../../configs/roban/m4_6_w005.json)
2. **核对已完成训练。** 从两组实际日志确认退出码、结束轮次、有效转移、训练用时和安全事件，检查 Initial、每 500 轮里程碑、Best 与 Last。整理 1000 轮前后的训练指标与周期评估，将训练采样、周期评估和统一冻结复测分别统计。[启动脚本](../../tools/run_m46_ablation.sh)
3. **统一冻结复测。** 四个权重用同口径的 Newton 场景、原参考时钟与确定性 Actor。比较各组第 5000 轮，再复测与末轮不同的周期 Best，同一份权重的别名只测一次。名义种子用 1001–1003，原组合初态扰动用 1101–1106。按种子检查跨策略起态一致，保持原终止、稳定承重与落脚判定。以 CUDA/MJWarp 为训练后端的验收依据。主机休眠后驱动失效，追加原生 CPU MuJoCo 的同种子复测作为辅助依据。
4. **比较步态、上身与安全指标。** 以完整四步、首次落脚、连续匹配和全程存活为主，辅以足位与 Root XY RMSE、接触一致率、主要终止原因、目标限幅和力矩饱和。按种子对齐共同有效时段后比较手臂、腰和手端误差，避免早停造成相位偏差。若周期与复测的结果不一致，检查具体种子、落脚时序和稳定承重。
5. **形成权重选择结论。** 优先确认候选能否维持基线的名义步态及扰动恢复，再比较上身收益。明确训练 seed 只有 0、冻结复测的样本数及可复现范围。报告集中保留必要的评估依据、数据来源和建议。[实验报告](../report/m4.6_report.md)
