# M5.1 足部朝向与承重稳定性计划

三组均从 M5.0 第 5500 轮加载 Actor、WM、Critic 及归一化缓冲区，重新创建 Adam、Replay 和学习率调度。F1/F2/F3 在每个环境复位时等概率采样，50% 的复位使用 M5.0 末阶段的完整初态偏差。每组 256 环境，以相同种子 0 进行 200 轮 Critic 预热，Actor、WM 及这两者的归一化在预热期间冻结。随后联合微调 2000 轮，Actor LR 为 5×10⁻⁵，WM/Critic 基础 LR 为 2×10⁻⁴，WM Window 4、BPTT 16。继续使用 M5.0 的 20 ms 控制步、8 个物理子步、固定站姿动作缩放和 Hard Clamp。[任务说明](../prompt/m5.1.md) · [A 配置](../../configs/roban/m5/m5_1_a.json) · [B 配置](../../configs/roban/m5/m5_1_b.json) · [C 配置](../../configs/roban/m5/m5_1_c.json)

| 组 | 支撑航向权重 | 法向角滑权重 |
| --- | ---: | ---: |
| A | 0 | 0 |
| B | 0.25 | 0 |
| C | 0.25 | 0.10 |

两只脚的足尖方向由模型的后跟圆柱指向前掌圆柱，均为 `leg_*6_link` 的局部 +X。实际和参考朝向投影到地面切平面，用 `atan2(cross_z, dot)` 取有符号差角。支撑航向使用有效计划支撑掩码，容许带 3°、Huber 尺度 10°。角滑使用可微 FK 的足部世界角速度，取 Z 分量与同帧参考的差，容许带 0.10 rad/s、尺度 0.50 rad/s。角滑权重为计划支撑乘最低足底角高度代理，代理沿用 `sigmoid((0.004−h)/0.003)`，停止该权重的直接梯度。两项分别用有效权重和归一，质量、配置权重与 0.02 s 各乘一次。选模用 Newton 的 10 N 实测承重，按完步和存活、恢复、承重、滑动及跟踪排序。[奖励实现](../../supermimic/integration/m51_foot.py) · [周期评估](../../supermimic/integration/m51_evaluation.py)

现有 Swing Orientation 的弦距离为 `||R−Rref||²_F / 2`，在摆动包络中用 0.30 rad 尺度的指数核，固定按两脚平均。Stance Position 在计划支撑期用 0.08 m 指数核。原 Slip 只使用计划支撑与高度代理加权的足底中心水平速度平方，尺度 0.20 m/s。Contact Schedule 以有效参考标签上的代理接触平方误差计分。Touchdown 使用摆动后半段至接触后 0.12 s 的事件窗，水平落脚点使用 0.12 m 长尾核，高度代理平滑过渡到承重代理。在 45 条实测轨迹上，A 与原 M5.0 奖励逐值一致。[原奖励](../../supermimic/roban_task.py) · [基线 CSV](../../outputs/m5_1/foot_baseline.csv) · [验收数据](../../outputs/m5_1/preflight.json)

正式微调由用户启动。每 250 轮保存，500 轮使用正常种子 1001–1003 评估各自完整时长。共用偏差用于终评候选排序，1201–1206 留出偏差和 H1–H4 用于选定后的验证。综合结果及正面、侧面和俯视视频在正式训练完成后生成。

```bash
bash tools/run_m51_training.sh --dry-run all
bash tools/run_m51_training.sh check
bash tools/run_m51_training.sh all
bash tools/run_m51_training.sh status
bash tools/run_m51_training.sh attach
bash tools/run_m51_training.sh resume c
```

`a`、`b`、`c` 可独立启动。每组的 `logs/train.csv`、`logs/console.log` 和 `checkpoints/last.pt` 位于 `outputs/m5_1/a_baseline`、`b_stance_yaw` 或 `c_yaw_angular_slip`。SwanLab 适配使用 `tools/sync_swanlab.py --roban_m51 --run_dir <组目录>`。训练结束后用 `bash tools/run_m51_training.sh evaluate` 运行终评，随后用 `bash tools/run_m51_training.sh visuals` 读取终评归档。[启动脚本](../../tools/run_m51_training.sh) · [复评报告](../report/m5.1_report.md)
