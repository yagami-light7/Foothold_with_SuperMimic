# M5.0 Roban 多参考跟踪计划

从 B1250 加载 Actor、WM、Critic 和归一化缓冲区，以新 Adam、新 Replay 和新调度进行 Warm Start。沿用 M4.11-B 的实际奖励、21 维位置目标控制、关节硬限位、物理参数和 0.20 s 上身过渡。Actor 历史与未来目标的形状为 10×69 和 320，Critic 输入为 970。 [任务说明](../prompt/m5.0.md) · [M4.11 复评](../report/m4.11_report.md)

## 数据与训练前验收

- 只读载入 M3.7.1 的 F1、F2、F3，保留 301、261、241 帧。审计时间、接触、手及足底 FK、限位和动态诊断。用同一站姿中心法生成 H1–H4，将它们留给最终候选。H3/H4 的交替步频取最邻近的整数周期，摆动比例按最近整数帧对齐生成器的离地和触地。
- 参考驻留 GPU，以打包索引和不可变库版本区分片段，Episode 首帧、局部时钟与身份维持异步复位和历史回放。F2 回归比较 Goal、Reward、手部参考、事件窗口和终止。独立 CUDA Newton 先运行 B1250 Zero-shot，再依次测试 8、32、256 环境和同组恢复。
- 训练采样、Replay、WM 与 BPTT 共用索引。归档全帧形状、实际 Replay 占比和性能，并核对留出参考在训练路径之外。[参考清单](../../configs/roban/m5_0_motion_library.json)

## 正式运行

| 阶段 | 本阶段轮次 | F1 / F2 / F3 的 Reset 概率 | Actor |

| WM/Critic 适应 | 1000 | 20% / 60% / 20% | 参数及归一化冻结 |

使用 256 环境、WM Window 4、BPTT 16、WM/Critic 基础 LR 2e−4。每 250 联合轮存档，每 500 联合轮评估，课程边界增加共用偏差评估。联合 1501 轮开始在 25% 的复位使用半范围扰动，3501 轮起在 50% 的复位逐步扩大至全范围。阶段切换查看 F2 与各步态完整率，并保留出现明显退化或物理异常的诊断。[训练配置](../../configs/roban/m5/m5_0.json)

## 独立复评

比较 B1250、适应后、各阶段优胜、Best Multi-Reference、Best Robust 与 Last。已见片段使用 1001–1003、1101–1106、1201–1206，按实际末帧与计划落脚数判断成功。冻结候选优先考虑三片段完整率、最差片段、恢复和足根跟踪。入选模型再评估 H1–H4。按片段报告观测窗、共同窗、完整轨迹和最差片段，并用原速统一策略回放展示三个时长。训练前验收和最终结果汇入 [m5.0_report.md](../report/m5.0_report.md)。

## 复现入口

从 SuperMimic 仓库根目录运行。B1250、训练参考及生成完成的 H1–H4 NPZ 的路径写入训练和参考清单。环境默认使用 `supermimic:latest`，可用 `DOCKER_IMAGE` 指定同版本镜像，用 `M50_REFERENCE_ROOT` 指定只读参考根目录。

```bash
bash tools/run_m50_training.sh preflight
bash tools/run_m50_training.sh start
bash tools/run_m50_training.sh status
```

中断后用 `bash tools/run_m50_training.sh resume` 恢复 Last。训练完成后可用 `bash tools/run_m50_training.sh evaluate` 复评并重渲染。SwanLab 沿用 `tools/sync_swanlab.py` 的 CSV 入口，M5.0 参数为 `--roban_m50 --run_dir outputs/m5_0`。

若要重建 H1–H4，在 Motion Generator 仓库以 `configs/m3_7.yaml` 为母版将下面四条放入独立临时配置，使用 `.venv/bin/python -m roban_motion.m3_7 --stance-centered --config <临时配置> --output <临时输出目录>`。每组配置设置对应的 `swing_ratio`。生成通过后提取各组 `forward/<编号>/reference.npz`，按约定命名为 `outputs/m5_0/heldout/<编号>.npz`。

| 配置行 | swing_ratio |
| --- | ---: |
| `[H1, forward, 0.140, 45, 0.0, 0.0450]` | 0.40 |
| `[H2, forward, 0.200, 60, 0.0, 0.0550]` | 0.40 |
| `[H3, forward, 0.155, 53, 0.0, 0.0475]` | 0.39622641509433965 |
| `[H4, forward, 0.185, 48, 0.0, 0.0525]` | 0.3958333333333333 |
