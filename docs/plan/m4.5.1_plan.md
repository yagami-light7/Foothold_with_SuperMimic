# M4.5.1 鲁棒性诊断计划

1. 核对四档冻结权重和评估契约。重复原周期与独立评估，比较单环境和并行环境，定位轨迹首个分叉并导出第四次落脚逐帧证据。
2. 用配对种子复现组合扰动，再分离七个单因素。对主要风险因素追加样本及幅度扫描，按时间顺序检查首次落脚失稳和跌倒。
3. 用同一真实起态对照 Actor 和 Newton 响应，分解足部、上身和 Critic 梯度。在三种公共状态—动作数据上验证 WM 预测和局部有限差分。
4. A–D 实测完成后，以 M4.3 第 4500 轮为共同初始化，对 0、0.02、0.05、0.10 各运行 250 轮短训。保持原物理保护，统一评价名义与扰动条件。
5. 保留必要权重、逐帧证据、归档、图和视频，报告归因的证据强度。在 `docs/report/m4.5.1_report.md` 记录结果和采用建议。
