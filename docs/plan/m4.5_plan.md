# M4.5 实施计划

1. 审查原始 F2 的九个上身关节、相位、姿态及接触几何，用 M4.3 真实回放量化差异。若发现明显不合理的参考姿态，记录证据并暂停正式训练。
2. 核对现有 `body_prior` 公式、质量门控与非对称观测。用冻结 Actor、真实 Newton 采样和 WM 做奖励与梯度检查。
3. 前置检查通过后，从 M4.3 配置仅增加 `body_prior_weight=0.10`，用原 Hard Clamp 从随机初始化训练 5000 轮。保留每 500 轮检查点和原物理保护。
4. 统一复测 M4.3 与 M4.5，比较落脚、上身关节、手端、平滑度、物理稳定性和匹配样本上的 WM 梯度。以完整步态优先选权重。
5. 将本轮证据和建议整理到 `docs/report/m4.5_report.md`，仅保存必要轨迹、图、视频和审计数据。
