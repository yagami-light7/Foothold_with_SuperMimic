# M4.2 实施计划

1. 用 Roban 源模型的足底几何、质心和静态站立测试评估动作中心。再用 F2 全段统计确定动作缩放，并验证参考关节目标可以由线性输出还原。
2. 增加独立的固定站姿动作模式。真实采样与 Replay 保留加噪后的连续动作，World Model 和 BPTT 使用从同一限位目标反算的动作，力矩奖励与评估共用目标映射。用检查点契约记录动作语义。
3. 复用 M4.1 v2 物理配置、异常保护和 Newton 评估。保持一份训练指标与当前最佳检查点，记录周期评估的首次摆动和落脚。
4. 验证 21 关节顺序、动作边界梯度及真实目标的一致性。用零动作、小动作、F2 关节目标和随机 Actor 实测，再用短训练检查 WM、BPTT、Critic、保存、恢复和独立评估。配置正式训练为 5000 轮，实际执行控制在烟测规模。
5. 在 `docs/report/m4.2_report.md` 记录站姿来源、缩放、F2 逐关节统计、实测结果与命令。清理烟测的临时文件。
