## 冻结权重的统一 Newton 复测

以确定性 Actor 和 `m44_evaluation.scene / trial / evaluator` 重跑四档第 5000 轮，以及与 Final 不同的三个周期 Best。M4.5 的 Best 与 Final 是同一文件，只测一次。每个权重和条件独立创建一个世界，沿用原 F2 和同一 Hard Clamp，同种子初态逐元素比较的绝对容差为 $10^{-7}$。名义种子为 1001–1003，组合扰动为 1101–1106。组合范围沿用历史设置，Root XY 各 ±0.020 m，高度 +0.006 到 +0.012 m，roll/pitch 各 ±1°、yaw ±3°，关节角 ±0.010 rad，Root 线速度、角速度分别 ±0.020 m/s、±0.050 rad/s，关节速度 ±0.10 rad/s。完整四步同时要求连续匹配与全程存活。落脚保留 ±0.20 s 时间窗、100 mm 水平误差上限与至少 0.06 s 连续承重，接触阈值为 10 N。跟踪误差和接触一致率按轨迹等权平均。驱动力矩饱和率使用额定值的 99% 作为阈值，并汇总全部已执行转移。上身奖励按统一系数 0.10 离线重算，训练时的实际系数保留在各检查点中。

### 上身平滑性与加速度突变（CUDA）

从真实关节速度每 20 ms 取样，以 $\Delta\dot q / \Delta t$ 算关节加速度、以 $\Delta^2\dot q / \Delta t^2$ 算 jerk。臂速度、臂加速度 RMS 和绝对加速度 P99/Max 覆盖双臂八关节，jerk RMS 覆盖双臂和腰共九关节。动作 RMS 取这九个 Actor 原始输出的二阶差分 $a_{t+2}-2a_{t+1}+a_t$，使用无量纲动作单位。每条轨迹先独立差分，再汇总关节与时刻。主表包含起始状态到第一控制步的变化。

## 采用结论

**当前默认继续使用 M4.3 Best（第 4500 轮，`body_prior_weight=0.00`）。** 在 CUDA 上它维持名义 3/3、扰动首落 6/6 和完整四步 4/6。M4.3 末轮的扰动完整数为 5/6，首次落脚为 5/6，名义和扰动的 Root XY 误差均高于第 4500 轮。

`0.02` 末轮是改善上身平滑和足位误差的候选，当前 CUDA 名义落脚结果限制其使用。`0.05` Best 是兼顾名义四步和上臂位置跟踪的候选，扰动尾部加速度、腰误差与力矩饱和仍高。后者是这次训练的中期窗口，四档等预算比较使用第 5000 轮权重。本轮证据范围为一条 F2 参考和一个训练种子（seed 0）。
