## 奖励与配置

复用 `roban_task.py` 的计算。每步上身贡献为 $0.10\times0.02\times Q\,[0.7\exp(-\mathrm{MSE}_{\rm arm}/0.5^2)+0.3\exp(-\mathrm{MSE}_{\rm waist}/0.5^2)]$。手臂 MSE 均匀取八个关节，腰取单关节。腰部项为正，Root 高度与方向先验权重为零。奖励总和进入真实采集与 WM 想象共享的 `mdp.reward`。日志回报上界随新增项从每步 0.089 升至 0.091，$\gamma=0.99$ 时 Critic bootstrap 上界从 8.9 升至 9.1。

`quality` 是 F2 运动学有效与优化收敛标签的交集，和机器人当前姿态偏差无关。F2 全帧均为 1，780 步 × 两个 M4.3 权重的 Mean/P10/P90 也均为 1。Actor 观察历史 `10×69`、Goal `320`，Critic `970`。实测冻结输入的 Goal 与旧任务逐值一致，Actor 的观测/Goal 归一化器仍为 `69/320`，未引入完整上身目标通道。上身误差通过奖励参与优化。

启动前逐项比较 `configs/roban/m4_3.json` 与 `configs/roban/m4_5.json`，唯一差异为新增 `body_prior_weight=0.10`，原解析默认值为 0。Hard Clamp、256 环境、5000 轮、seed 0、Actor LR 0.0002、WM-only 1000、WM Window 4、BPTT Horizon 16 与 Newton 8×2.5 ms 沿用基线。Best 先按完整率、连续落脚和首次事件筛选。通过这些条件的权重，足 RMSE/Root XY RMSE 在最优值上依次只允许 2/5 mm 差距，再比较手臂、腰部误差、加速度、上身奖励及力矩饱和。[正式配置](../../configs/roban/m4_5.json)

## 采用决策

保留 M4.3 Hard Clamp 和原奖励作为默认配置。`body_prior_weight=0.10` 在 F2 上有明确的手臂跟踪收益，也降低了名义足误差和实际力矩饱和，但未保持统一独立评估中的四步成功率与初态鲁棒性。腰部误差、末段承重和右肘过度屈曲仍需处理，继续保留 M4.5 作为可选实验配置。

扩展到 Multi-Reference 时，先由 M4.3 建立多条参考的成功率和扰动基线，再把弱上身先验作为独立对照。对每条参考记录上身相位与质量，优先验收首次和末次落脚、承重持续时间与完整步态，以公共状态—动作的 WM 诊断和留出参考区分训练分布内收益与泛化。
