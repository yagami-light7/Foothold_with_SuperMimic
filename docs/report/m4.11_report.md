# M4.11 Roban 双手末端跟踪报告

**独立复评推荐 B1250 为 M4.11 的综合候选。** B1750 的名义手部几何跟踪更准，B1250 在留出扰动下恢复更好。当前奖励适合保留为 M5 对照，正式冻结仍需更多参考和初态验证。A 延续 C9000 奖励，B 增加躯干局部双手位置 Huber 项。[实验计划](../plan/m4.11_plan.md) · [M4.10 报告](m4.10_report.md)

## 奖励和检查点

使用 `base_link` 的位姿和左右 `l_handball`、`r_handball` 的原点，沿用 M4.10 的轴定义、零偏置和 WXYZ 四元数顺序。机器人和参考分别在各自躯干坐标系内取手部位置，按同一个 50 Hz 步后 F2 帧比较。碰撞与手部位置共享同一份可微 FK，手部参考缓存一次。Newton 真实奖励、Replay 重算和 WM 想象使用同一个奖励函数。[实现](../../supermimic/integration/m411_hand.py) · [任务奖励](../../supermimic/roban_task.py)

公式为 `r_hand = −0.02 × 0.10 × Q × [H(u_L) + H(u_R)] / 2`，其中 `u_i = max(‖p_i − p_i_ref‖ − 0.03, 0) / 0.10`。H 在 `u ≤ 1` 时为 `u²/2`，之后为 `u − 0.5`。M4.10-C 的正奖励上界仍为 0.101。训练 CSV 同时保留各组真实奖励、想象奖励及共同 M4.10-C 计分。

C9000 保存了 Actor、WM、Critic、五组输入或输出归一化缓冲区、三组优化器、RNG 和采集步进调度进度。Checkpoint 中没有 Replay 或独立 Scheduler 状态，旧 LR 可见于训练配置及优化器。两组仅继承网络和归一化状态，重建 Adam 与 Replay。200 轮 Critic 预热期间，Actor、WM 和各自归一化缓冲区冻结。联合微调共 2000 轮，Actor LR 固定为 `5e-5`，WM 和 Critic 基础 LR 为 `2e-4`，从本轮联合轮次计算原调度。[训练入口](../../supermimic/train.py)

### 模型推荐与 M5

**推荐 B1250 作为 M4.11 综合候选。** 以名义四步与足根跟踪达标为前提，优先比较两套扰动的完整四步和存活。12 条扰动中，B1250 完整 7 条、存活 8 条，B1750 完整 6 条、存活 7 条，B2000 完整和存活均为 5 条。B1250 保持名义 5.79 mm 足误差、较低的上身加速度与 jerk，双肘近限位及双踝裁剪均为 0%。B1750 适合展示名义手部和上臂跟踪质量。M4.10-A10000 保留为共用扰动恢复对照。

**暂不将当前 Reward 冻结为 M5 的正式版本。** B1250 的留出四步与存活刚达到 3/6 和 4/6 的工程门槛，另外两个 B 候选的留出恢复低于门槛。B1250 在两个特定扰动下还有明显的关节速度高频功率抬升。当前证据覆盖单条 F2 和一个训练种子，适合把这套奖励及 B1250 固定为下一阶段对照，再用多参考和独立初态验证正式冻结条件。
