# M5.1 足部朝向与支撑稳定性

## 训练及周期结果

A、B、C 均从 M5.0 第 5500 轮开始，以相同种子在 256 环境完成 200 轮 Critic 预热和 2000 轮联合微调。每组采集 1,440,768 条转移，保留 8 个周期检查点。峰值设备显存分别为 2050、2050、2052 MiB，三组日志的 EPA 复位、无效转移和 Newton 物理异常计数均为 0。三组末轮的正常 F1/F2/F3 复评均达 3/3，训练进程以状态 0 退出，tmux 会话随之结束。[实施计划](../plan/m5.1_plan.md)

三组 Initial 中的 Actor、WM、Critic 及归一化状态都与 M5.0-5500 逐张量相同，Adam 初始状态为空。200 轮预热后，Actor 和 WM 逐张量保持初值，Critic 已更新。三者在联合末轮均有更新，末轮的物理和数据契约与源检查点一致。

## 独立 CUDA Newton 复评

**推荐 C1500 作为 M5.1 直走策略。** 已见步态 45/45、未见步态 35/36，与本轮重跑的 M5.0-5500 完整数相同。正常步态的支撑 Yaw RMSE 从 23.21° 降到 2.45°，实际承重法向角速度 RMS 降低 84.7%，足底 RMSE 宏平均从 7.94 降到 7.39 mm。三条正常步态的 Root XY RMSE 为 52.10–54.05 mm，均高于 50 mm 目标。[C1500 检查点](../../outputs/m5_1/c_yaw_angular_slip/checkpoints/iter_1500.pt)

### 复评设置与完成率

RTX 4060 Laptop GPU 上完成 378 条独立闭环轨迹，372 条通过完整任务，378 条均存活到参考末帧。F1/F2/F3 时长分别为 6.00、5.20、4.80 s。已见片段使用正常种子 1001–1003、共用偏差 1101–1106 和留出偏差 1201–1206，H1–H4 使用前两组种子。片段与种子相同的 Reset 初态在候选间满足 10⁻⁷ 容差，M5.0 本轮对历史归档的 81 个 Reset 初态逐元素一致。物理与落脚判据沿用 M5.0 的 20 ms 控制步、8 个子步、10 N 承重阈值、卸载 ≥0.10 s、抬升 ≥20 mm、落脚时差 ±0.20 s、落点平面偏差 ≤100 mm 及连续承重 ≥0.06 s。完整任务要求存活并从首步开始连续匹配全部四次计划落脚。[评估入口](../../supermimic/integration/m51_evaluation.py) · [逐种子指标、轨迹和共同窗](../../outputs/m5_1/cuda_evaluation.npz)

足底误差取完整成功试次。C1500 的 H1/1104 在 1.50 s 计划首落附近距目标仅 0.11 mm，未满足连续承重。后三次事件分别匹配，整段存活 4.80 s。M5.0 的失分在 H2/1104 的首落承重。B2000 的三个 H2 正常种子均因第二次落脚超出时间窗、第四次落脚承重不足而失分，另有 H4/1103 未通过末次承重。

- **A1000** 的未见步态完成数最高，支撑 Yaw 和承重角速度较 M5.0 升高。两项指标的改善集中在加入足部奖励的 B、C 组。
- **B2000** 把支撑 Yaw 从 23.21° 降至 2.93°。C1500 在此基础上又降低约 45% 的承重法向角速度，并把未见完整数从 32/36 提升到 35/36。
- **C1500** 的足部方向、承重稳定性、上身平滑性和恢复表现最均衡，可作为后续直走对照。若优先考虑 50 mm 的 Root XY 指标，C2000 的三个正常片段为 49.55、49.29、48.87 mm，已见筛选完成 27/27。C2000 的计划支撑承重和水平速度逊于 C1500，且缺少留出偏差和未见步态数据。当前结论限于单个训练种子、已测试的直走参考与初态范围。
