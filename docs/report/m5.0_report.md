## 工程结论

1. 正式训练从多参考清单进入，F2 的专用入口留作历史回归和旧实验复现。
2. 各环境独立采样并异步复位，GPU 打包索引、回放 Episode 身份和片段末端均已验证。
3. 第 5500 轮的单个策略完成了三种已见直走步态的所有种子。
4. Warm Start 保持了 F2 正常完整率。5500 的正常足底误差比 B1250 增加约 1.86 mm。
5. F1/F3 足部精度、接触一致性和上身平滑性改善。三片段手部及上臂方向保真仍有提升空间。
6. 共用偏差完整数从 B1250 的 7/18 提升至 18/18，留出偏差从 6/18 到 18/18。多参考与扰动课程共同作用，恢复改善的单因素归因需要对照试验。
7. 梯度审计记录少量负余弦及 F1 第 3500 轮的暂时退化。F2 的周期完整率保持 3/3。
8. 已见片段上的 WM 短时预测达到毫米级足底误差，8 步误差较 1 步上升约五倍。
9. 四个留出直走组合均能从正常初态完成。较长且较慢的 H2 在偏差下出现一次首落承重失败。
10. 建议将 M4.11-B Reward 作为转弯、转圈和后退的冻结对照。扩展动作的接触和航向表现需通过各自的闭环复评。
11. 当前直走证据表明既有未来目标足以表示这些步态。若更宽步频范围、在线变频或片段过渡出现持续相位错误，再做显式 Gait Phase 和 Frequency 的消融。
12. 已为 M3.12 接入提供统一 Episode 锚点和批量参考查询接口。M5.0 Replay 使用不可变离线库的身份重建，在线参考仍需以版本一致的快照接入。
