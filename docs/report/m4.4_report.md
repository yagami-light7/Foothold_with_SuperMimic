# M4.4 Roban 位置目标裁剪消融

**保留 M4.3 Hard Clamp 作为 Roban 的默认方案。** M4.4 续训完成 5000 轮。名义回放中，M4.4 的完整四步跟踪为 0/3，M4.3 两档均为 3/3。无裁剪恢复了部分未饱和状态的局部响应，实际力矩饱和、止挡推压和 WM 梯度误差均增加。

## 动作与执行器契约

线性 Actor 输出 $a$，使用 Roban 默认站姿 $q_0$ 和逐关节缩放 $\alpha=0.35\,\tau_{\max}/K_p$。M4.3 向 Newton 下发 `clamp(q0 + alpha*a, q_min, q_max)`，WM 使用 `(q_target - q0)/alpha`。M4.4 配置 `m4_unclipped_pd_target=true` 后，下发 `q0 + alpha*a`，同时将原始 $a$ 送入 WM。Replay、动作历史和动作变化率沿用采集时的原始动作，力矩代理使用对应模式的目标。BPTT 外推与真实下发采用同一映射。旧配置继续走原映射，正式训练的检查点验证会拦截跨模式加载。

上游 SuperMimic 依赖 `mjlab_research`，从环境读取动作缩放和偏置，`Dynamics.proc` 用线性目标归一化 WM 输入。MJLab Tracking 选择默认站姿作偏置，`clip` 默认为 `None`。上游 G1 缩放系数为 `0.25`。其隐式位置执行器禁用了位置指令限幅，对自身力矩限幅。本实验沿用 Roban 的 `0.35` 和原有 PD、摩擦、阻尼、机械限位与终止条件。[SuperMimic 依赖](https://github.com/HybridRobotics/supermimic/blob/main/pyproject.toml#L15-L20) · [Runner 读入缩放与偏置](https://github.com/HybridRobotics/supermimic/blob/main/src/supermimic/runners/supermimic_runner.py#L145-L154) · [Dynamics.proc](https://github.com/HybridRobotics/supermimic/blob/main/src/supermimic/models.py#L76-L87) · [Tracking 配置](https://github.com/HybridRobotics/mjlab_research/blob/main/src/mjlab/tasks/tracking/tracking_env_cfg.py#L120-L128) · [ActionTermCfg](https://github.com/HybridRobotics/mjlab_research/blob/main/src/mjlab/managers/action_manager.py#L20-L30) · [线性 Action 处理](https://github.com/HybridRobotics/mjlab_research/blob/main/src/mjlab/envs/mdp/actions/actions.py#L142-L151) · [G1 缩放](https://github.com/HybridRobotics/mjlab_research/blob/main/src/mjlab/asset_zoo/robots/unitree_g1/g1_constants.py#L263-L271) · [执行器参数](https://github.com/HybridRobotics/mjlab_research/blob/main/src/mjlab/utils/spec.py#L325-L350)

`mujocolab/mjlab` 主仓同样先做线性缩放和偏置，仅在提供 `clip` 时裁剪。其位置动作下发时扣除编码器偏置，默认编码器偏置为零的情形对应上述公式。[主仓位置目标处理](https://github.com/mujocolab/mjlab/blob/main/src/mjlab/envs/mdp/actions/actions.py#L141-L150) · [编码器偏置补偿](https://github.com/mujocolab/mjlab/blob/main/src/mjlab/envs/mdp/actions/actions.py#L194-L205)

本地调用链为 `M4TrackingSim.pd_target` → `F2TrackingMDP.standing_pd_target` → `TrackingSim.advance_physics` → Isaac Lab `Articulation.set_joint_position_target_index` / `write_data_to_sim` → `actuator_control.py` 集成关节指令 → Newton `solver_mujoco.py` 把 `joint_target_q` 写入 `mjw_data.ctrl` → MJWarp `forward.py` 和 `constraint.py`。模型回读的 42 个 P/D 驱动均关闭 `ctrllimited`，21 个关节均启用 `jnt_limited` 和 `jnt_actfrclimited`。Roban 在关节级限制 P+D 合驱动力矩。机械约束参与求解，角度仍可能在负载下有限越界。所用运行时为 Isaac Lab 41.0.0、Newton 1.8.0.dev0、MuJoCo Warp 3.15.0、Warp 1.17.0。调用入口见 [`m4_task.py`](../../supermimic/integration/m4_task.py)、[`env.py`](../../supermimic/env.py) 和 [`train.py`](../../supermimic/train.py)。

左踝 `leg_l5_joint` 实测 $q_0=-0.702200$ rad，范围 $[-0.872665, 0.523599]$ rad，$\alpha=0.129500$ rad/动作，$K_p=200$ N·m/rad，$K_d=1.54919$ N·m·s/rad，限幅 74 N·m。站姿距下限 0.170465 rad，原始动作小于 −1.31633 即要求低于下限，大于 9.46563 才越过上限。位置梯度在 M4.3 的裁剪区为零，M4.4 恒为 $\alpha$。合力矩饱和和机械约束仍可削弱动作对真实状态的影响。

### 映射、回放和梯度

动作映射、既有 Swing-Aware 奖励、足部计算与 WM/BPTT 回归共 39 项通过，覆盖极端动作、实际目标与 WM 输入对齐、位置梯度、力矩代理饱和及跨模式检查点拒绝。8 环境、12 轮的 CUDA/Newton smoke 完成 368 条训练转移，实跑 WM、Replay、Critic 与 Actor BPTT。第 12 轮 WM loss 1.0885，Actor 梯度范数 0.475，实际无 EPA reset、无失效转移或致命异常。该短测用于检查完整链路，正式训练使用单独的随机初始化。

额外在 CPU 用旧权重做 8 个起态 × 16 步的有限值测试。加固定动作偏置后，原始动作峰值 35.96，45.05% 位置指令越界，Replay 与 WM 输入逐项相等。奖励力矩代理与手算限幅逐项相等，80.36% 的代理值达到额定力矩的 99%。总 Actor 梯度范数 108.74，足部动作梯度 RMS 为 $3.43\times10^{-5}$，损失与梯度均有限。该项测试只验证数值链路。

一组补充 Newton 单步有限差分用 M4.3 Final 的 38 个回放状态与原始动作。选择 26 个双侧扰动 $a\pm0.15$ 均越过左踝下限的状态。Hard 下实测左踝纯轴 $|d\tau/da|$、$|dq/da|$、足部奖励 $|dR/d a|$ 的均值分别为 $7.4\times10^{-6}$ N·m、$4.6\times10^{-8}$ rad、$3.8\times10^{-9}$，均接近数值噪声。无裁剪下对应为 22.80 N·m、0.01520 rad、0.001908。本组左踝驱动力矩峰值从 13.83 升至 47.61 N·m，仍未达到 74 N·m。38 个起态中末子步的受载机械止挡由 20 个增至 32 个。取消裁剪恢复了这组指令的局部响应，也增加了机械止挡负担。

## 正式训练

使用 [`m4_4_unclipped.json`](../../configs/roban/m4/m4_4_unclipped.json)。逐项配置比较只有 `m4_unclipped_pd_target` 新增。正式训练采用 256 环境、5000 轮、seed 0、WM-only 1000 轮、Actor LR $2\times10^{-4}$、WM 窗口 4、BPTT horizon 16。F2 为 261 帧、50 Hz，Newton 每个控制步使用 8 × 2.5 ms 子步。训练通过容器内的 `roban-m44` tmux 会话启动，显式 `--fresh_start`，每 500 轮保存恢复点并按 M4.3 规则重排名。

### 训练中的关节异常

1751–2000 轮的 160,000 条候选转移中，10 条因关节守卫被拦截并局部重置，占 0.00625%。该窗口全部/左踝/右踝原始目标越界率为 15.62%/90.41%/56.45%。实际力矩饱和率为 8.42%，最大实际关节越界 0.788 rad，最大关节速度 174.88 rad/s。M4.3 同窗口对应为 0 次拦截、0.456% 饱和、0.191 rad 越界、61.33 rad/s。两组口径相同。

首个异常记录于第 1880 轮。三个环境在步后 F2 第 46、44、65 帧左右分别出现两个左踝和一个右踝向上越界。原始位置目标为 2.456、2.351、4.811 rad，实际关节越过 0.523599 rad 上限达 0.753、0.781、0.771 rad。末物理子步实际驱动力矩三例均为 +74 N·m，同轴约束广义力约 −165、−171、−121 N·m。起始关节速度已为 +89、+101、+110 rad/s，此前快照可见两侧速度反转和目标正负切换。三个世界均有同侧小腿与足部部件自接触，溢出位为 0，末子步约束数 11/27/33，均低于 1024。证据支持驱动饱和与高速撞击止挡共同造成过冲，逐子步先后关系超出这份快照的时间分辨率。[第 1880 轮快照](../../outputs/m4_4_unclipped/dynamics_fault_pre_resume.npz)

用同一份快照的状态、求解器暖启动和逐步原始动作，做 3 环境 × 8 步的真实 Newton 反事实回放。无裁剪复现 3 次守卫触发，Hard 为 0 次。无裁剪/Hard 最大实际越界为 0.781/0.137 rad，峰值速度 150.83/84.61 rad/s，全部关节的末子步实际力矩饱和率为 32.54%/16.27%。两个回放均无求解器溢出或 Fatal。动作映射差异足以触发或避免本批过冲。

### 左踝的物理灵敏度

- 保持 64 个 M4.3 Final 起态及原始动作相同，52 个起态的纯左踝双侧扰动始终越界。Hard 的真实力矩和足奖励斜率近于零。无裁剪的真实平均绝对力矩斜率为 21.38 N·m/动作、关节角度斜率为 0.02250 rad/动作、足奖励斜率为 0.001064。受载止挡计数从 34/64 增至 58/64，最大止挡反力矩从 67.41 增至 84.28 N·m。两组的左踝额定力矩尚有余量。这组配对证实无裁剪可以恢复局部响应，也更容易推向止挡。
- M4.4 Final 自身 78 个起态中，21 个起态的两侧纯左踝扰动均达到同向力矩饱和。真实足奖励绝对斜率均值为 $7.10\times10^{-9}$，WM 为 $2.72\times10^{-4}$，21 例的真实反应均低于符号统计阈值。54 个主动推向受载止挡的起态中，28 个双侧斜率达到统计阈值，符号一致率仅 25%，Pearson 为 −0.263。对全部左踝有效斜率，M4.4 Final 预测改善而实际下降为 21/40。力矩饱和造成部分物理响应消失，机械止挡附近其余样本的模型方向也容易失真。[分层有限差分与 BPTT 结果](../../outputs/m4_4_unclipped/evaluation/wm_audit.json)

## 后续训练选择

M4.4 的 5000 轮结果没有提高 F2 落脚跟踪，并增加了实际力矩饱和、止挡推压和部分关节的越界。配对 Newton 回放复现了无裁剪引起的瞬时过冲。最终冻结回放均能完成 5.2 s 且无求解器级故障，仍存在持续止挡负荷。局部可微性在有力矩余量的部分状态恢复，标准化公共样本和各自轨迹的足奖励梯度可靠性均降低。

后续多 Reference 训练建议用 M4.3 Hard Clamp 作为已验证起点，并继续记录首次落脚、完整步态、力矩饱和、止挡负荷与扰动成功率。当前证据来自一个训练种子和单条 F2，且 M4.4 续训包含 Replay 重建和 500 轮 WM 恢复。多 Reference 泛化与严格等量 Actor 更新的消融仍需另行验证。将无裁剪保留为独立实验开关，旧权重应使用其原动作映射。
