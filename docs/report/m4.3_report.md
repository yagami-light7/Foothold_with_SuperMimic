# M4.3 · Swing-Aware Reward 与 WM 梯度诊断

**结论。** 5000 轮新训练完成。统一 Newton 复测中，第 5000 轮和最佳权重第 4500 轮均在 3/3 次试验中完成首次摆腿、首次落脚及全部 4 次计划落脚。第 5000 轮 Foot RMSE 为 0.0285 m，同环境 M4.2 v2 为 0.2611 m。WM 在本策略分布上预测更准，固定旧数据上的同奖励梯度一致率未改善。训练末段左踝仍有一个关节长期触发裁剪。

## 奖励设计与训练前验证

主实验以 `configs/roban/m4/m4_3.json` 固定参数，从随机初态重新训练。沿用 Roban 21 DoF、F2 原始 261 帧、Actor `10×69+320 → 21`、970 维 Critic、WM 窗长 4、BPTT 16 步、原优化器、线性动作和 `0.35 τmax/Kp` 的限位目标。Newton 每控制步为 `8×2.5 ms`，沿用 EPA 隔离与无效 Replay 掩码。独立比较的旧权重为 M4.2 v2 第 5000 轮。 [主配置](../../configs/roban/m4/m4_3.json) · [M4.2 v3 诊断](m4.2_v3_report.md)

记 \(K_\sigma(d)=1/(1+d^2/\sigma^2)\)，\(S(x)=x^2(3-2x)\) 在 \([0,1]\) 内取值，区间外取端点。\(c\) 是计划接触，\(\phi\) 是同一只足的 F2 摆动进度，\(h\) 是在世界系测得的物理足底最低角点。\(m=(1-c)\,\mathrm{valid}\,S(\phi/0.15)S((1-\phi)/0.15)\)。实际 Reward 为表中各项乘权重再乘 `0.02 s`，足部项按两足平均。位置、朝向、速度和落脚点都从同一 F2 时钟取得。真实 Newton 步后和 imagined WM 步后共用映射。

| --- | ---: | --- |
| 摆动位置 | 1.00 | \(mK_{0.12}(\lVert p-p_{\mathrm{F2}}\rVert)\)。长尾覆盖大误差。 |
| 摆动朝向 | 0.25 | \(m\exp(-\lVert R-R_{\mathrm{F2}}\rVert_F^2/(2\cdot0.30^2))\)。 |
| 摆动离地 | 0.75 | \(mK_{0.018}(h-h_{\mathrm{F2}})\)。既鼓励低足抬起，也鼓励摆动末期降到同相位参考。 |
| 支撑位置 | 1.00 | \(c\exp(-\lVert p-p_{\mathrm{F2}}\rVert^2/0.08^2)\)。 |
| 接触时序 | 0.25 | \(\mathrm{valid}[1-(b-c)^2]\)，\(b=\operatorname{sigmoid}((0.004-h)/0.003)\)。另一足仍按计划支撑。 |
| 落脚 | 0.50 | \(wK_{0.12}(\lVert p_{xy}-p_{\mathrm{land},xy}\rVert)H\)。摆动后半段 \(w=S(2\phi-1)\)，\(H\) 为参考离地高度得分。落脚后 \(w=1-S(\Delta t/0.12)\)，按 \(S(\Delta t/0.06)\) 将 \(H\) 平滑交给支撑概率 \(b\)。 |

## 正式运行

启动时本机镜像内的 tmux 名为 `roban-m43`，容器宿主 PID 为 `20460`，pane PID 为 `62`。实验采用 256 世界、5000 轮、种子 0、前 1000 轮 WM-only、Actor LR `2e−4`。每 500 轮刷新 `last.pt` 并独立评估，每 1000 轮保留里程碑。独立评估以完整跟踪、连续落脚、首次落脚、首次摆动、足根误差和存活依次排序。保留被评估到的首个成功检查点及一份对应视频。
