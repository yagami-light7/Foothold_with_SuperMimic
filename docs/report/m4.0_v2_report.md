# M4.0 V2 网络与 400 次迭代配置审查

**历史实验的前三项符合预期，第四项不符合。** Roban F2 使用默认关节姿态为动作中心，采用非对称 Actor–Critic，并给 Actor 提供本体历史和未来足部目标。Critic 实际接收 400 维输入，只有当前状态、仿真上下文和与 Actor 共享的 320 维 F2 目标。

| 核查项 | 400 次迭代判定 | 实际实现与证据 |
| --- | --- | --- |
| 1. Default-centered Action Mapping | **符合** | `TrackingSim.pd_target()` 以模型中立角为中心。历史检查点为旧的任务契约 v1，保存 21 路缩放与动作限幅。基线报告记录第 400 次迭代起步目标与重置姿态 RMS 差为 0.624 rad。[env.py](../../supermimic/env.py#L260)、[历史报告](m4.0_report.md) |
| 2. 非对称 Actor–Critic | **符合** | 独立 `Policy` 与 `Critic` 使用不同输入。Critic 额外获得完整状态和仿真上下文。历史 `no_critic=false`，最终检查点有 394 次 Actor Adam 更新和 1,576 次 Critic Adam 更新。[train.py](../../supermimic/train.py#L329)、[最终检查点](../../outputs/m4_0/checkpoints/last.pt) |

## 动作中心与 PD 目标

`q_default` 来自 Roban MJCF 的 21 个受控铰链在模型 `qpos0` 中的角度，当前模型读取结果为 21 个 0 rad。仿真将这些角度登记为关节默认姿态，并按 Roban 规范顺序构造目标，写入时按关节名映射到模拟器顺序。F2 重置则写入第 0 帧的根部和关节状态，M4 关闭重置扰动及域随机化。

\[
\bar a_j=\operatorname{clip}(a_j,-20,20),\qquad
q_{\mathrm{target},j}=q_{\mathrm{default},j}+\xi_{\mathrm{joint},j}
+\alpha_j\bar a_j,\qquad
\alpha_j=0.25\,\tau_{\max,j}/K_{p,j}.
\]

`Policy.dec` 末层为线性输出。历史训练采样加入标准差 0.1 的高斯探索噪声，再由 `bound_action()` 限幅。逐关节 \(\alpha_j\) 为 0.0440625–0.1875 rad/动作单位，腰腿 \(K_p=200\)，手臂 \(K_p=80\)。历史 M4 中 \(\xi_{\mathrm{joint}}=0\)，因此零动作目标为模型中立位。F2 参考参与重置、目标构造和跟踪奖励，逐步动作中心固定。审查开始时工作区已有可显式选择的 `reference_residual` 分支，其中心为当前帧 `motion.q[f]`，结果裁剪到关节硬限位。[roban.py](../../supermimic/roban.py#L56)、[robot.py](../../supermimic/robot.py#L9)、[env.py](../../supermimic/env.py#L98)、[m4_task.py](../../supermimic/integration/m4_task.py#L165)

## Actor 与 Critic 的实际输入

| 网络／输入 | 维度 | 数据来源与预处理 |
| --- | ---: | --- |
| Actor 关节位置与速度 | 每帧 21 + 21 | Newton 关节状态，按规范顺序排列。位置减 `q_default`，速度乘 0.1。 |
| Actor 根部角速度与投影重力 | 每帧 3 + 3 | 根部角速度从世界转到机体坐标后乘 0.25，重力方向为机体坐标的 `-R[2, :]`。 |
| Actor 上一步动作 | 每帧 21 | 实际下发的有界动作，重置时为零。 |
| Actor 本体历史 | 10 × 69 = 690 | 当前帧与前 9 帧，控制间隔 20 ms。重置时用当前观测填充历史。训练给关节位置、缩放后速度、角速度和投影重力加均匀噪声，按通道用 `obs_norm` 归一化后展平。 |
| 双足未来目标 | 每个时刻 2 × (3 + 6 + 1 + 1) = 22 | F2 左右脚足底位置、姿态 6D、计划接触和单脚摆动相位。位置相对当前根部，位置与姿态都转换到当前根部航向坐标。接触来自 F2 日程。 |
| 根部未来目标与时间 | 每个时刻 3 + 6 + 1 = 10 | F2 根部相对位置、航向坐标下的姿态 6D、实际前视时间。10 个时刻标称为 0.1–1.0 s，接近参考末端时截到末帧。 |
| Critic 当前完整状态 | 55 | 相对环境原点的根部位置 3、`wxyz` 四元数 4、世界坐标根部线速度与角速度各 3、规范顺序的关节位置与速度各 21。Newton 实测状态作为 Replay 起点，后续想象状态由 WM 推进。该分支使用当前状态向量，未拼入 Actor 的 690 维历史。 |
| Critic 仿真上下文 | 25 | 1 个摩擦参数、21 个关节偏移、3 个躯干质心偏移。按 `(μ−0.75)/0.45`、`joint_offset/0.01`、`com_offset/0.05` 缩放。历史 M4 的原始上下文固定为摩擦参数 1、两类偏移 0。 |
| Critic 共享目标 | 10 × 32 = 320 | 和 Actor 共用同一份原始目标 `g`。Critic 将它与 55 + 25 维拼接，再按 `critic.norm` 统一归一化，输出标量价值。 |

6D 姿态取旋转矩阵的前两列并展平。Actor 的 320 维目标单独由 `goal_norm` 归一化后送入 Encoder。本体观测不含根部绝对位置、根部线速度或仿真上下文。目标坐标变换仍依赖当前根部位置与航向，历史仿真从 Newton 状态取得这两个量。Critic 的额外特权主要来自当前完整根部状态和仿真上下文，输入不含未来实测机器人状态。[roban_task.py](../../supermimic/roban_task.py#L153)、[m4_task.py](../../supermimic/integration/m4_task.py#L43)、[rotations.py](../../supermimic/rotations.py#L110)、[mdp.py](../../supermimic/mdp.py#L132)、[train.py](../../supermimic/train.py#L504)

如启用 `--critic_use_body_reference`，`body_goal()` 为每个未来时刻追加根部相对位置 3、姿态 6、线速度 3、角速度 3、21 个参考关节角及 21 个参考关节速度。参考速度在航向坐标下表达，关节速度乘 0.1。与原有足部和根目标合用时，Critic 输入将为 **970 维**。历史检查点与运行实参均显示该开关为 `false`。[motion_reference.py](../../supermimic/motion_reference.py#L269)、[roban_runtime.py](../../supermimic/roban_runtime.py#L46)

## SuperMimic 训练结构

- `goal_mode=roban_foot` 使用 `Policy.enc` 编码 F2 运动目标，320 维经 MLP 和 `tanh` 得到 32 维 latent。项目的 Shared Decoder `Policy.dec` 接收 latent 与 690 维本体历史，输出 21 维动作。历史 M4 使用单个目标编码器，`DualEncoderPolicy` 属于另一任务分支。[networks.py](../../supermimic/networks.py#L141)、[train.py](../../supermimic/train.py#L333)
- WM 用 Newton Replay 拟合状态增量。历史网络从 101 维输入（55 维航向不变状态、21 维动作、25 维上下文）预测 54 维增量。Actor 每次更新在冻结的 WM 中做 6 步想象，沿奖励和 Critic 末端价值做 BPTT。独立 Critic 在想象转移上拟合 \(\lambda\)-return，历史 `critic_real_batch=0`。[networks.py](../../supermimic/networks.py#L67)、[train.py](../../supermimic/train.py#L528)、[train.py](../../supermimic/train.py#L561)
