# M4.5.1 上半身运动先验鲁棒性诊断

## 对照与实验约束

冻结诊断比较 M4.3 第 4500/5000 轮和 M4.5 第 4500/5000 轮。M4.5 `best.pt` 与 `last.pt` 都指向第 5000 轮，不作为新增策略样本。保持原始 261 帧 F2、Hard Clamp、动作比例 0.35、Isaac Lab 3.0 Newton 的 8×2.5 ms 物理步长，以及原有终止和落脚判定。使用无探索噪声的确定性 Actor。当前 Git HEAD `c83ac5168ca6a9e2e22aec596e849e1eaea207a4`，工作树包含既有 M4.4/M4.5 变更和本轮诊断代码。历史周期与独立档案均按只读使用。[M4.3 配置](../../configs/roban/m4/m4_3.json) · [M4.5 配置](../../configs/roban/m4/m4_5.json)

历史 M4.5 的第 4500/5000 轮周期评估均为 3/3，第 5000 轮独立评估为 1/3。先重新执行两个原入口并加入不同批量规模，定位可复现的实际差异。检查点中四档训练的 `imagination_contract.bootstrap_upper_bound` 都是 `None`，此前 M4.5 报告列出的 8.9/9.1 是数学上界，实际 F2 trainer 的 bootstrap 沿用原契约。诊断保留实际 bootstrap 行为。

## A. 重复评估和第四次落脚

M4.5 各入口重复两次，每次使用种子 1001、1002、1003。原周期使用 `m43_evaluation` 的实际 CLI，在临时目录写产物。原独立使用 `m44_evaluation` 的 `scene` 和 `trial`。另做每个种子重建单世界与三个世界同批评估。全部 54 条新轨迹都存活 5.2 s，未触发 EPA 或 Fatal。M4.3 第 4500/5000 轮的独立基线均为 3/3。

第 4500 轮共 24/24，第 5000 轮为 15/24。第 5000 轮的九次失败全部出现在第四步，两种原入口均能复现失败。权重别名、归一化状态、物理参数、参考时钟和首帧输入已核对。名义评估固定 Torch 种子、关闭 reset 扰动和动作探索。历史两入口对同一权重的真状态、首帧 Actor 输入、Action 和 PD Target 一致。三世界与单世界的首帧动作最大相差 $7.15\times10^{-7}$，PD Target 相差 $1.79\times10^{-7}$ rad。seed 1002/1003 的 reset 帧 solver 原始 qpos/qvel 读回存在滞后，第一物理步后差异归零。历史三个种子在 0.10 s 已可见约 $1.53\times10^{-5}$ N 法向力差和 $2.86\times10^{-5}$ warmstart 差，Action 差在 0.16–0.28 s 才超过 $10^{-6}$。三个种子的首个大于 1 N 的足力差分别在 2.12、3.78、2.42 s，首个大于 1 mm 或 1 mrad 的状态差在 2.42、3.76、3.80 s。新第 5000 轮同入口重复中，首次 >1 N 的时间中位数为 2.12 s，首次 >1 mm 或 1 mrad 为 2.42 s，12 对有 11 对出现接触二值分叉。证据与微小接触差经闭环放大一致，无法单独识别 CUDA Graph、批内排列或求解器的具体运算。

历史 `seed 1001/1003` 的独立第四步在 4.50/4.42 s 落地，XY 误差 17.7/16.4 mm，均在原 0.10 m 及 ±0.20 s 判定窗内。右足垂直速度为 −0.553/−1.565 m/s，对应周期成功试次为 −0.063/−0.067 m/s。独立法向力为 1103→860→0 N 和 1027→703→0 N，只连续承重 0.04 s。周期试次承重 0.72 s。新复测这两种子同样出现 `stable_support` 失败。快速触地后失载及支撑转换对微小扰动敏感，是这一缺步的直接证据。落脚位置和时窗在这两例中均达标。

新试次中，第 5000 轮 15 个成功第四步承重范围 0.06–0.74 s，中位数 0.06 s。八个已合格到达的失败只承重 0.02–0.04 s，落脚误差 4.3–27.7 mm，另一次失败由落脚时机判定。成功和失败的落地速度范围重叠，说明支撑转换与冲击共同影响结果。历史 seed 1001 在承重中断时右足由下落 −0.553 m/s 反向至 +0.855 m/s，4.54 s 两足法向力均为 0，Root 高度反弹自 0.647 至 0.661 m。

## C. 上身补偿、同状态闭环与梯度

历史组合扰动的五个配对失败种子上，M4.3 Best→M4.5 Final 的初始双支撑手臂速度 RMS 为 3.925→2.869 rad/s，首摆变为 1.872→2.588 rad/s。用编译后的刚体质量和惯量，相对整机 CoM 求和上身横向角动量，初始/首摆由 0.335/0.513 升至 0.495/0.628 kg·m²/s。初始/首摆根倾角 RMS 7.61°/4.35°→7.86°/5.66°，右脚 <10 N 帧比例 5.13%/6.34%→15.38%/29.27%。手臂在首摆使用更多动作，支持“补偿方式发生变化”，缺少“所有相位补偿被压低”的证据。

## E. 短训初始化与权重消融

A–D 实测结束后启动四组 250 轮短训。源权重为 `outputs/m4_3/checkpoints/best.pt` 的第 4500 轮。复用 Actor、WM 及两者正常化状态。Critic 随共同 seed 0 重新初始化，四组都重建三个 Adam、Replay、RNG 和轮次。这样连零权重组也按同一方式适配，奖励标尺的变化由新的 Critic 学习。每组先用 128 步采样填充，再做 25 轮 WM-only，余下 225 轮联合更新。四组维持原学习率、优化器策略、256 环境和原 Newton 保护。

初始化单独检验物理、数据、动作、观测及目标契约，要求源任务与目标任务仅差 `body_prior_weight`。原 `--resume` 仍执行完整同任务检查。原镜像 CPU 核对四组复制后的 Actor、WM 及归一化逐张量相等，额外更改落脚奖励会被拒绝。[短训共用配置](../../configs/roban/m4/m4_5_1_finetune.json)

零权重组首跑在第 250 轮的分项梯度记录时中止。零权重上身项是常量，记录器误向它请求自动梯度。记录器修正为常量项计零范数后，用相同源和 seed 0 从第 0 轮重跑该组。失败发生在日志诊断路径，原物理保护没有触发。

四组均正常退出，每组 192,768 条实际转移，包含 128 步预填充。训练和两次周期评估的计时分别为 177.0、176.0、165.7、165.4 s。四组训练均无关节异常重置和 EPA 重置。有效配置除输出路径、上身权重及其派生的奖励配置外逐项相同。周期 Best 依次为第 125、250、125、250 轮。每组保留初始、第 125、最终权重，相同轮次的 Best/Last 使用硬链接。

## 结论与下一阶段

1. **名义第四步的直接失败是支撑时间不足。** M4.5 第 4500 轮在四个入口 24/24，第 5000 轮为 15/24。第 5000 轮虽然有更小的落脚误差，但八个失败只在窗口内承重 0.02–0.04 s。两个原入口都能复现，首帧对照也不支持用权重或 reset 路径错误解释全部差异。
2. **初态高度是当前证据最强的扰动触发因素。** M4.5 Final 单独扰动高度只存活 1/6，原组合扰动没有首落。动作、姿态和足力的分叉早于跌倒，且有一例在首次计划落脚附近恢复了足力却未到位。短闭环换入旧上身只部分改善足误差，局部 BPTT 竞争以首次摆动与落脚更清楚。WM 在自身失败分布上误差增大并出现方向反转，但在同一失败数据上比旧 WM 更准。共同结论有相位与分布依赖，单凭手臂 RMSE、`root_height` 终止或 WM 误差都不足以建立唯一主因。
3. **下一阶段建议沿用 M4.3 Best、Hard Clamp 和 `body_prior_weight=0`。** 这是本轮组合扰动仍有 4/6 完整四步的冻结基线。短训零权重对照也失去步态，当前结果不足以选出小权重候选，也不支持直接开启新一轮 5000 轮 Fresh Start。如需继续比较上身先验，应先复现保持原步态的零权重续训，分开验证 Critic、归一化和 Replay 重建的影响，再考虑重复不同训练种子。
4. **Multi-Reference Footstep Tracking 先建立跨参考的接触验收。** 当前 F2 训练每次从第 0 帧开始，未用 B 的配对初态扰动做 reset，采集仍有动作探索和策略反馈。接触与恢复样本覆盖不足是合理假设，尚未通过数据覆盖干预验证。扩展时保留 F2 回归集，按参考分开报告名义与配对扰动，先以完整落脚、首次稳定承重和存活为门槛，再比较脚、Root 和上身误差。用失败状态复查 WM 的足部、净空和落脚斜率，确认恢复行为在 Newton 中也有收益。
