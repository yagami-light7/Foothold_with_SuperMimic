# M4.9 Roban F2 长程训练与上身姿态先验

**三组均完成 10000 轮。独立 CUDA 复评中，没有一份 M4.9 权重同时达到步态、双肘姿态和平滑性目标。** A9000 名义足 RMSE 降至 11.62 mm，但扰动四步仅 2/6。Soft Body Prior 的 C9500 名义四步 3/3，双肘近限位降到 0.0% / 3.1%，扰动四步只有 1/6，持续段加速度与 jerk 均高于历史基线。M4.8-C Best 继续作为控制质量基线，C9500 保留为姿态候选。

## 实验设置与训练完成情况

A 将 M4.8-C 的预算增至 10000 轮。B 在 A 上加权重 0.02 的原 Body Prior。C 在 A 上加权重 0.02 的 Soft Body Prior，把输入姿态误差换成 \(d_j=\max(|q_j-q_{\mathrm{ref},j}|-\delta_j,0)\)。肩、肘、腰的 \(\delta_j\) 分别为 0.35、0.25、0.20 rad。臂和腰分别计算 \(\exp(-\operatorname{mean}(d^2)/0.5^2)\)，以 0.7 / 0.3 加权并乘参考质量和控制步长。离线标定在 45 条历史轨迹及其上的 500 个 BPTT 起点复算，C 候选的先验梯度范数中位数为足部的 0.77%，B 为 0.68%。此前三组已通过小规模 CUDA Smoke Test。[实验计划](../plan/m4.9_plan.md) · [先验标定](../../outputs/m4_9/prior_calibration/results.json)

三组共用 Roban 21-DoF、原始 F2（261 帧，50 Hz，5.2 s）、8×2.5 ms Newton、256 环境、seed 0、前 1000 轮 WM-only、WM Window 4、BPTT 16、`10×69 + 320 → 21` Actor 和 970D Critic。沿用站姿偏置和 Hard Clamp，动作比例为 `0.35 × effort_limit / Kp`，上身 0.20 s Smoothstep 和二阶差分权重 0.02。第 5000 / 10000 轮 Actor LR 为 0.000199809 / 0.000199235，与 250000 轮固定衰减周期相符。三组实际 Initial 与历史 M4.8-C Initial 的 Actor 26、WM 20、Critic 9 个张量逐值相同，Adam 初始状态为空，均从头训练且没有 Resume。[A 配置](../../outputs/m4_9/a_long_baseline/config/train.json) · [B 配置](../../outputs/m4_9/b_original_prior/config/train.json) · [C 配置](../../outputs/m4_9/c_soft_prior/config/train.json)

## 验收与后续

A 的长训在本次运行中稳定了名义四步，并降低了第 9000 轮的跟踪误差。扰动成功数在三个受测点为 2、2、1，双肘也随训练重新靠近限位。B 的早期姿态收益在后半程消失，扰动表现持续落后。C 的低近限位优势延续到末轮，但名义步态反复，且扰动表现和平滑性仍落后于基线。

保留 A9000 作为长训名义对照、C9500 作为姿态对照、M4.8-C Best 作为控制基线。下一步优先复核首摆卸载、根高和第一次落脚，继续用同种子扰动筛选权重。三组各只训练一次，全部结果来自同一 F2，跨训练种子和动作参考的稳定性仍待检验。[后续计划](../plan/m4.9_plan.md)
