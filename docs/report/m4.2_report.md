# M4.2 动作映射与训练准备

## 映射与训练链路

新增 `standing_offset` 模式，配置为 `configs/roban/m4/m4_2.json`。论文附录 A 使用固定默认姿态加线性偏移。M4.2 在此基础上用 Roban 的机械限位裁剪位置目标。 [SuperMimic 论文附录 A](https://arxiv.org/pdf/2610.28480#page=13)

\[
a_t \in \mathbb{R}^{21},\qquad
\alpha_j=0.35\,\frac{\tau_{\max,j}}{K_{p,j}},\qquad
q_{\mathrm{target}}=\operatorname{clamp}(q_0+\alpha\odot a_t,q_{\min},q_{\max}).
\]

| 环节 | 实际语义 |
| --- | --- |
| Actor | 共用 Decoder 的末层直接输出 21 维线性动作。采集时加标准差 0.1 的高斯噪声。想象和评估用确定性输出。 |
| Newton | 按真实关节顺序下发上述位置目标，继续使用 M4.1 v2 的 8×2.5 ms 子步、8 ms 限位时间常数、逐关节阻尼和异常保护。 |
| Replay、历史、动作正则项 | 保存并使用实际加噪后的连续动作。沿用动作变化率项 `mean((a−a_prev)²)`。 |
| WM、BPTT、力矩奖励 | WM 的归一化、Replay 拟合和想象均使用 `a_eff=(q_target−q0)/alpha`。力矩代理读取同一 `q_target`。限位外动作对物理目标的直接梯度为零。 |

M4.1 以关节活动范围的中点和半范围映射 `tanh` 动作。M4.2 的零动作对应固定站姿，单位动作在未裁剪时增加 `0.35τmax` 的比例力矩。M4.2 的历史观测仍为 `10×69`，足部/根部目标为 320 维，Critic 总输入为 970 维。

## 站姿来源与 F2 表达能力

先用 Roban MJCF 检查全零站姿和站立时的足底、质心。使用模型原站宽 0.24882 m，固定躯干直立，在 0.67–0.75 m 高度上做双足位姿逆解。足踝目标为 `(-0.035, ±0.12441, 0.041)` m，双脚平行地面，两肘约屈曲 31°。先用原生 MuJoCo 对姿态做 3 s 定姿对照，选择 0.69 m 候选，然后用 Newton 复验。F2 仅用于后续动作范围统计。

同一 M4.1 v2 物理配置下，两个站姿的 Newton 测试都维持 3 s 双脚支撑。全零站姿的峰值倾角和水平漂移为 11.82°、11.28 cm。新站姿为 3.05°、1.34 cm。F2 第 0 帧到站姿动作中心的关节 RMS 偏差为 0.374 rad，源全零关节中心为 0.647 rad。

## 测试结果

5 项 M4.2 动作单元测试和 17 项既有 Roban 回归测试通过。测试覆盖超过 ±20 的线性输出、噪声后的原始动作入 Replay、21 关节索引、不同参考的一致性、Newton/WM/奖励的目标一致性及四步 WM 反传。限位内 `∂a_eff/∂a=1`，限位外为 0，WM 反传在未饱和通道有有限非零梯度。

RTX 4060 上使用 4 个 Newton 环境，从 F2 起态执行四组动作，在跌倒时终止。实测提交的 PD 目标和 WM 重建目标一致，机械目标裁剪、末子步力矩饱和、物理异常均为零。

| F2 起态测试 | 平均存活（s） | 最大实测越界（rad） | 峰值关节速度（rad/s） | 峰值力矩占限幅 |
| --- | ---: | ---: | ---: | ---: |
| 零动作 | 1.38 | 0.048 | 47.1 | 78.9% |
| `a∈[-0.1,0.1]` 小幅动作 | 1.47 | 0.050 | 47.5 | 80.1% |
| F2 关节参考目标 | 1.10 | 0.000 | 5.9 | 34.3% |
| 随机初始化 Actor 加探索噪声 | 1.45 | 0.051 | 47.3 | 83.4% |

256 环境训练烟测完成 16 轮，其中前 4 轮仅更新 WM，累计 43,008 条有效转移。真实和 BPTT 的目标裁剪均为 0，实测力矩饱和 0，物理异常 0，最大实测关节越界约 0.062 rad。末轮窗口的 WM / Actor / Critic Loss 为 0.818 / −0.531 / 0.00788，Actor 梯度范数约 0.976，训练显存记录为 1,265 MiB。第 16 轮定期评估生成了 `best.pt`，三个闭环测试均存活 1.10 s。

使用同一配置从 `last.pt` 恢复到第 18 轮，期间真实与想象目标裁剪仍为 0，实测力矩饱和率不超过 0.03%。独立评估比较了初始、早期、第 18 轮和既有最佳检查点，按原排序指标选中第 4 轮以更新 `best.pt`。第 18 轮闭环存活 1.20 s，足部和根部 RMSE 为 0.089 m、0.234 m，首次摆动和落脚成功率均为 0%。新模式的训练入口已具备正式运行条件，步态质量需由正式训练和评估确认。

## 文件与运行

- `roban_runtime.py`、`integration/m4_task.py`、`train.py` 和独立评估接入新动作契约。在现有训练表记录动作分布、真实/想象目标裁剪、力矩饱和、越界和物理异常。
- `integration/m4_dynamics.py` 与 `integration/m4_action_diagnostics.py` 提供定姿和动作读回。`tools/test_m4_action_mapping.py` 覆盖动作与反传回归。
- 正式配置为 256 环境、5000 轮，每 1000 轮冻结评估最新和已有最佳检查点。评估记录首次摆动、落脚、生存和跟踪误差，只更新一份结果。实际 CLI 已验证 M4.1 检查点会被动作契约校验拒绝。

```bash
bash tools/run_roban.sh m4-train --roban_config configs/roban/m4/m4_2.json \
  --log_dir outputs/m4_2/checkpoints --iterations 5000 --fresh_start

bash tools/run_roban.sh m4-train --roban_config configs/roban/m4/m4_2.json \
  --log_dir outputs/m4_2/checkpoints --iterations 5000 \
  --resume outputs/m4_2/checkpoints/last.pt

bash tools/run_roban.sh m4-evaluate --out outputs/m4_2 --seeds 1001 1002 1003 --no_video
```
