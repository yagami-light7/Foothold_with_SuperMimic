# M4.7 启动冲击诊断与平滑奖励预备验收

首步冲击发生在 Actor 下发目标之后。M4.3 Best 名义种子 1001 的右肘从 −1.8132 rad 接收 −0.1245 rad 的首个 PD 目标，8 个 Newton 子步的实际驱动力矩均达到 37 N·m。0.10 s 过渡将首个控制周期平均加速度从 2570.6 降至 10.3 rad/s²，但同种子重复回放的扰动首落由 12/12 降至 6/12。0.20 s 过渡的名义完整四步为 0/3。保留原始启动执行，正式配置与启动脚本等待通过步态门槛的方案。平滑权重 0.02 已完成离线标定及隔离 CUDA Smoke。[实验计划](../plan/m4.7_plan.md) · [M4.6 证据](m4.6_report.md)

## 冻结诊断的口径

使用 M4.3 Best 4500、M4.6 先验 0.02 的第 5000 轮及 0.05 的第 4500 轮。沿用 Roban 21-DoF、原 F2 261 帧、50 Hz 控制、Newton 8×2.5 ms、原 PD 参数和落脚判定。RTX 4060 Laptop GPU 在原训练镜像上运行，Newton 为 1.8.0.dev0，MuJoCo Warp 为 3.15.0。完成 90 条有效闭环回放及 16 条关闭 CUDA Graph 的起步探针，每条探针覆盖 10 个控制周期与 80 个物理子步。EPA、无效转移和 Fatal 均为 0。同种子首态的逐元素比较容差为 \(10^{-7}\)。主机通过诊断进程作用域内的 sleep/idle/lid inhibit 保持运行。

名义使用 1001–1003，组合扰动使用 1101–1106。完整四步要求连续匹配且全程存活。首次落脚沿用 ±0.20 s 时间窗、100 mm 水平偏差、至少 0.06 s 连续承重及 10 N 接触阈值。完整回放存有逐试次落脚时间和承重时长，驱动力矩饱和以额定值的 99% 为阈值。[闭环统计](../../outputs/m4_7/startup_diagnosis/results.json) · [50 Hz 轨迹](../../outputs/m4_7/startup_diagnosis/rollouts.npz) · [400 Hz 探针统计](../../outputs/m4_7/startup_diagnosis/probe/results.json) · [400 Hz 轨迹](../../outputs/m4_7/startup_diagnosis/probe/rollouts.npz)

## 首条指令如何产生冲击

F2 Reset 加载参考的第 0 帧关节位置和速度，物理刷新只执行 forward。此时 PD 目标为实际 Reset 关节角。Actor 的 10 帧观测历史由真实首帧重复填充，Previous Action 通道存原始 Actor 动作，Reset 时为零。M4.3 Best 使用冻结归一化，名义首帧最大标准化绝对值为 2.64，Previous Action 通道的最大值为 0.83。第一条训练转移中的原 Action Rate 项已经生效，该试次加权贡献为 −0.00338。等效 Reset 动作实验将右肘历史设为 −7.8035，首条 Action Rate 贡献为 −0.00823。[Reset 与历史](../../supermimic/env.py) · [F2 执行](../../supermimic/integration/m4_task.py) · [奖励与归一化探针](../../supermimic/integration/m47_startup_audit.py)

原映射为 \(q_{\mathrm{hard}}=\operatorname{clamp}(q_0+\alpha a,q_{\min},q_{\max})\)，其中 \(\alpha_j=0.35\tau_{\max,j}/K_{p,j}\)。右肘 F2 姿态比默认中心低 1.2632 rad。Actor 首次输出 2.6288，使原始目标跨到 Reset 姿态上方 1.6887 rad。右肘 \(K_p=80\)、\(K_d=0.98\)，初始比例力矩约 135.1 N·m，速度反馈的量级约 0.0016 N·m。首个控制步的右肘机械限位力为零，Hard Clamp 前后目标相同，实际驱动力矩触及限幅。首步结束后右肘速度为 51.4131 rad/s。

## 平滑项实现与离线标定

从关节名称解析腰和双臂九关节。新增 \(r_{\mathrm{smooth},t}=-\operatorname{mean}_{j\in\mathcal J_{\mathrm{upper}}}(a_{j,t}-2a_{j,t-1}+a_{j,t-2})^2\)，其加权贡献为 \(0.02\,w_{\mathrm{smooth}}r_{\mathrm{smooth},t}\)，其中 0.02 为控制 dt。每个 episode 的头两条指令屏蔽该项，原 Action Rate 照常计入。Replay 为想象起点保留上两步 Raw Action、真实 Reset 姿态与步龄。Newton 下发 Hard Clamp 后的过渡目标，Replay/WM 使用由该目标反算的 Effective Action，BPTT 使用同一可微映射并保留新动作的跨时间梯度。Actor 的观测权限和网络维度沿用 M4.3。[共享动作变换](../../supermimic/integration/m47_control.py) · [Replay](../../supermimic/buffer.py) · [奖励](../../supermimic/roban_task.py) · [训练](../../supermimic/train.py)
