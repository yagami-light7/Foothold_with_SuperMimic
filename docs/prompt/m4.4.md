# M4.4 — SuperMimic 原生 Action Mapping 与左踝裁剪消融实验

## 任务目标

目前 M4.3 已经成功训练 Roban 21-DoF 机器人在 Isaac Lab 3.0 + Newton/MJWarp 中跟踪 F2 Foot/Root Reference，实现完整 4 次计划落脚。

但是第 5000 轮存在：

- 训练窗口总体 PD Target Clamp Ratio 约 12.29%。
- 独立评估总体 Clamp Ratio 约 15.01%。
- `leg_l5_joint` 训练末段 Clamp Ratio 高达 95.4%。
- 部分关节的 BPTT 动力学梯度在 Clamp 区间直接为零。

本次目标：

**研究关节位置目标硬裁剪是否限制了 SuperMimic 的控制能力和可微优化，并通过与 M4.3 完全对齐的训练实验，验证官方风格 Action Mapping 是否有优势。**

要求完成代码检查、物理对照、正式训练、独立评估及 WM 梯度分析。

## 四、任务 C：构建严格对照的 Action Mapping

建立可配置的 Action Mapping：

### A：M4.3 Hard Clamp，原基线

\[
q*{\mathrm{target}}=
\operatorname{clamp}
(q_0+\alpha a,q*{\min},q\_{\max})
\]

### B：SuperMimic-style Unclipped Target

\[
q\_{\mathrm{target}}=q_0+\alpha a
\]

实际执行力矩仍按原有 PD 与执行器限幅：

\[
\tau=
\operatorname{clip}
(K*p(q*{\mathrm{target}}-q)-K*d\dot q,
-\tau*{\max},\tau\_{\max})
\]

以上力矩公式用于说明控制契约，具体实现必须核对现有 Newton Actuator 及其实际执行结果，不允许重复施加力矩或改变原动力学实现。

### 重要：保持 WM 与 Newton 一致

原 M4.3 的 WM 使用裁剪后的等效动作。

对于新模式：

\[
a*{\mathrm{eff}}=
\frac{q*{\mathrm{target}}-q_0}{\alpha}
=a
\]

如果没有其他动作变换，WM 应直接学习实际生效的线性 Action。

必须检查：

- Newton Position Target
- Replay Action
- WM Input
- BPTT Action Mapping
- Torque Reward
- Action Rate Reward
- Actor 历史观测

确保所有环节的控制语义一致。

特别检查两种 Action Mapping 的局部梯度。

无 Target Clamp 时：

\[
\frac{\partial q\_{\mathrm{target}}}{\partial a}=\alpha
\]

但注意，实际物理执行器在力矩饱和时仍可能失去局部控制灵敏度。

因此，不得把非零 Position Target 梯度直接等同于有效真实动力学梯度。
