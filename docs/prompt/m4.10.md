## 1. 项目背景

请首先阅读项目中的历史实验报告及对应代码：

- `m4.2_v3_report.md`
- `m4.3_report.md`
- `m4.5_report.md`

- `m4.7_report.md`

- `m4.9_report.md`

重点检查 `roban_task.py`、Reward 实现、Actor/Critic、World Model、BPTT、Action Mapping、Replay Buffer 和独立 CUDA Newton Evaluation。

目前采用 SuperMimic + Asymmetric Actor-Critic 架构：

- Actor：本体历史观测 + Foot/Root Goals。
- Critic：本体观测 + 完整 Motion Reference。
- Actor 输出 Roban 21 个关节的控制动作。
- World Model 提供可微动力学预测。
- Actor 通过 BPTT 优化奖励及 Critic Bootstrap。

M4.9 已完成三组 10000 iterations 训练。

目前主要问题：

1. 足部跟踪精度已经较高，A9000 的正常初始状态 Foot RMSE 达到 11.62 mm。
2. Root XY 跟踪误差仍然较大，多组达到 90–120 mm。
3. 上半身姿态明显不自然，存在手臂横向伸展、异常抬肩、过度屈肘等现象。
4. Soft Prior 虽然缓解了双肘长期接近机械限位的问题，但没有得到自然且平滑的摆臂。
5. 原 Body Prior 的姿态约束效果在训练后期明显退化。
6. 左踝目标指令长期超出合法范围，部分权重需要裁剪的比例达到 100%。
7. 初始状态存在偏差时，策略的完整四步成功率仍然较低。
8. 当前 Reward 主要强调足部任务，没有显式 Root Tracking Reward，上半身姿态奖励也过弱。

M4.10 不再以单纯提高 Return 为目标，而是优化全身运动质量。

在保留已有足步任务能力的基础上，实现：

- 精准的足部位置与姿态跟踪。
- 正确的摆腿、支撑和落脚时序。
- 合理的 Root 位置、高度与运动方向。

- 协调的上半身摆臂。
- 平滑的关节运动和控制指令。
- 较好的初始状态偏差恢复能力。

本轮重点回答：

1. Root Tracking 是否能够改善整体身体姿态及下肢运动质量？
2. Dead-zone Huber Posture Prior 是否比原指数姿态奖励更有效？
3. 两种奖励同时使用时，能否获得自然、精准且稳定的全身步态？

暂时仍使用原始 M3.7.1 F2 Reference，不引入新的 M3.9/M3.10 Reference。

## 4. 新增 Root Tracking Reward

### 4.1 设计原则

目前 Actor 已经接收 Root Goals，但 Reward 不包含显式参考 Root 跟踪。

因此，Policy 可能通过身体位置偏移、过度屈膝、异常躯干姿态等方式降低足部跟踪难度。

本轮增加 Root Tracking，但不要求机器人严格复刻 Reference Root。

由于现有 Motion Generator 的参考轨迹尚未完全满足动力学约束，需要保留机器人自主调整身体位置和姿态的空间。

采用带容许区间的长尾奖励。

定义：

\[
K_\sigma(d)=\frac{1}{1+(d/\sigma)^2}
\]

### 4.2 Root XY Tracking

定义：

\[
e_{xy}=\|p_{root,xy}-p_{root,xy}^{ref}\|_2
\]

\[
d_{xy}=\max(e_{xy}-\delta_{xy},0)
\]

奖励：

\[
r_{root,xy}=K_{\sigma_{xy}}(d_{xy})
\]

配置：

| 参数 | 数值 |
|---|---:|
| Weight | 0.30 |
| Tolerance | 0.03 m |
| Sigma | 0.10 m |

容许范围内不产生 Root XY 姿态纠正梯度，超出范围后逐渐降低奖励。

应在统一世界坐标系或与其等价的环境局部坐标系中计算 Root 位置误差。

确保不同环境的 origin offset 不会造成错误。

不得使用机器人当前 Root 位置重新对齐 Reference，从而消除真正需要跟踪的位置误差。

### 4.3 Root Height Tracking

定义：

\[
d_z=\max(|z-z^{ref}|-\delta_z,0)
\]

奖励：

\[
r_{root,z}=K_{\sigma_z}(d_z)
\]

配置：

| 参数 | 数值 |
|---|---:|
| Weight | 0.15 |
| Tolerance | 0.02 m |
| Sigma | 0.06 m |

该项用于限制不合理的身体高度和过度屈膝，但不强制机器人精确跟踪 Root 高度。

### 4.4 Root Heading Tracking

定义：

\[
e_\psi=
|\operatorname{wrapToPi}(\psi-\psi^{ref})|
\]

\[
d_\psi=\max(e_\psi-\delta_\psi,0)
\]

奖励：

\[
r_{heading}=K_{\sigma_\psi}(d_\psi)
\]

配置：

| 参数 | 数值 |
|---|---:|
| Weight | 0.15 |
| Tolerance | 5°，约 0.087266 rad |
| Sigma | 0.25 rad |

需要正确处理：

- Quaternion 顺序与坐标系。
- Yaw 周期边界。
- ±π 附近的最短角度误差。
- WM 预测姿态的可微计算。
- 接近零误差时的梯度数值稳定性。

暂时不增加严格的 Roll/Pitch Reference Tracking，继续保留现有 Upright Reward。

### 4.5 Root 奖励汇总

\[
R_{\mathrm{root}}
=
0.30r_{root,xy}
+0.15r_{root,z}
+0.15r_{heading}
\]

Root 奖励总配置权重为 0.60。

每控制步最大正奖励贡献：

\[
0.60\times0.02=0.012
\]

所有参数在整个训练过程中固定，不针对不同 Reference 单独标定。

## 5. Dead-zone Huber Posture Prior

### 5.1 当前姿态奖励的问题

原 Body Prior 对双臂八关节的 MSE 统一计算指数奖励。

原 Soft Prior 在此基础上引入姿态容许范围。

主要不足：

- 单个肩关节的异常容易被整体平均误差稀释。
- 指数奖励在大误差时梯度逐渐衰减。
- 当前姿态奖励权重较小，无法充分约束异常抬肩和摆臂。
- 双肘远离机械限位不代表全身姿态已经自然。

M4.10 采用逐关节计算的 Dead-zone Huber Penalty。

### 5.2 姿态误差

对于每个关节：

\[
e_j=q_j-q_j^{ref}
\]

\[
d_j=\max(|e_j|-\delta_j,0)
\]

归一化：

\[
x_j=\frac{d_j}{\sigma_j}
\]

Huber 函数：

\[
H(x)=
\begin{cases}
\frac12x^2,&0\leq x\leq1\\
x-\frac12,&x>1
\end{cases}
\]

每个关节独立计算 Huber Penalty，再在对应关节组内取平均。

这样能够在姿态严重偏离 Reference 时保留持续的纠正梯度，同时避免二次惩罚在大误差区域产生过大的梯度。

### 5.3 Shoulder Posture Prior

Roban 双肩共六个关节。

\[
R_{shoulder}
=
-0.20\operatorname{mean}_{j\in shoulder}H(x_j)
\]

配置：

| 参数 | 数值 |
|---|---:|
| Weight | 0.20 |
| Tolerance | 0.20 rad |
| Sigma | 0.50 rad |

本轮主动收紧肩部姿态容许范围，以解决目前手臂横向伸展和异常抬肩的问题。

### 5.4 Elbow Posture Prior

Roban 双肘共两个关节。

\[
R_{elbow}
=
-0.10\operatorname{mean}_{j\in elbow}H(x_j)
\]

配置：

| 参数 | 数值 |
|---|---:|
| Weight | 0.10 |
| Tolerance | 0.25 rad |
| Sigma | 0.50 rad |

肘部容许范围沿用 M4.9 实际生效配置。

### 5.5 Waist Posture Prior

\[
R_{waist}
=
-0.05H(x_{waist})
\]

配置：

| 参数 | 数值 |
|---|---:|
| Weight | 0.05 |
| Tolerance | 0.20 rad |
| Sigma | 0.50 rad |

### 5.6 完整上半身姿态奖励

\[
R_{\mathrm{posture}}
=
Q_t
\left(
R_{shoulder}
+
R_{elbow}
+
R_{waist}
\right)
\]

其中 Q 为现有 Reference Quality Gate。

注意：

- 使用真实关节角度与同一时刻 Reference 关节角度计算误差。
- 不使用 Actor 原始动作代替关节姿态。
- 不使用 PD Target 代替机器人实际关节状态。
- 正确匹配 Roban 肩部六关节、肘部两关节和腰部一关节。
- 关节索引必须通过名称或已有可靠映射验证。
- 每个关节独立计算 Huber，再进行组内平均。
- 只乘一次 Reward Weight、Quality Gate 和 dt。
- 不得同时启用旧 Body Prior 或 Soft Body Prior。
- 容许范围内姿态惩罚为零，允许机器人自主平衡。
- 不针对不同 Reference 重新搜索参数。

本轮不增加下肢关节姿态跟踪奖励。

### 5.7 负惩罚与训练稳定性

新的 Huber Prior 是负惩罚，而原 Body Prior 是正奖励。

因此需要检查：

- 训练初期总奖励是否异常下降。
- Huber Prior 是否压制足部任务梯度。
- Critic Target 是否出现错误裁剪。
- 是否出现通过提前终止逃避姿态惩罚的倾向。
- 是否因上身姿态约束过强而无法完成首次摆腿。

不得简单假设新旧 Reward 权重具有相同的数学尺度。

## 7. 左踝长期动作裁剪诊断

M4.3–M4.9 长期存在左踝目标指令裁剪问题。

目前动作映射为：

\[
q_{\mathrm{pre}}=q_0+\alpha a
\]

\[
q_{\mathrm{target}}
=
\operatorname{clip}
(q_{\mathrm{pre}},q_{\min},q_{\max})
\]

其中：

\[
\alpha=0.35\frac{\tau_{\max}}{K_p}
\]

本轮首先进行诊断，不直接改变 Action Mapping。

### 7.1 检查内容

针对 `leg_l5_joint` 及其对应的右侧关节，核对：

- 关节名称、索引和左右对应关系。
- 机械位置限位。
- 关节轴方向。
- Reference 关节角度。
- 实际关节角度。
- 默认站姿 q0。
- Action Scale。
- Actor Raw Action。
- 未裁剪的目标角度。
- 裁剪后的 PD Target。
- 实际 PD Torque。
- 接触阶段与裁剪方向。
- 关节位置与速度误差。

明确区分：

1. 目标指令超出合法范围。
2. 实际关节角度超出机械限位。
3. 实际力矩饱和。

三者不能混为一谈。

### 7.2 梯度诊断

使用已有 M4.8-C Best、M4.9-A9000 和 C9500 的真实轨迹，检查：

- 足部 Reward 对左踝实际关节角度的梯度。
- Root Reward 对左踝动作的梯度。
- 姿态与稳定性 Reward 对下肢动作的影响。
- Hard Clamp 前后的局部动作梯度。
- Effective Action 梯度。
- 左踝 Raw Action 的直接动力学梯度。
- Actor 参数层面的总梯度。

不要仅根据 Hard Clamp 的数学性质断言整个 Actor 梯度为零。

需要通过实际 BPTT 梯度判断是否存在该动作通道长期缺乏直接纠正信号的问题。

### 7.3 Overflow Penalty 候选

如果确认长期裁剪造成明显的梯度问题，可以实现一个默认关闭的候选奖励：

\[
e_{\mathrm{overflow},j}
=
q_{\mathrm{pre},j}
-
\operatorname{clip}
(q_{\mathrm{pre},j},q_{\min,j},q_{\max,j})
\]

\[
r_{\mathrm{overflow}}
=
-\operatorname{mean}_j
H(|e_{\mathrm{overflow},j}|/0.1)
\]

候选权重为 0.05。

本轮三组正式训练均不启用该项。

仅完成必要诊断和可选实现，将其保留为后续独立消融候选。

不取消 Hard Clamp，不扩大机械限位，不擅自调整 PD 或 Action Scale。

## 9. 真实 Rollout、Replay 与 Imagined Rollout 一致性

这是本轮必须保证的核心契约。

真实 Newton Rollout 与 WM Imagined Rollout 应共用一致的 Reward 数学定义。

确保：

- 统一使用步后状态与对应步后 Reference。
- Root 位姿、关节角度和足部目标来自正确时间索引。
- Replay 中保存正确的原始动作与实际执行动作。
- Startup Smoothstep 后的 Effective Action 仍正确传递至 WM。
- Huber Prior 使用相应真实或预测关节状态。
- Root Tracking 使用相应真实或预测 Root 状态。
- Critic Target 使用新增后的完整 Reward。
- BPTT 中新奖励没有被意外 detach。
- 状态归一化和反归一化过程正确。
- Episode Reset 后的动作历史与时间索引保持正确。

检查 Reward 归一化上界、Critic Bootstrap 范围、训练日志及 Episode Return 分母。

M4.10 新增的 Root 正奖励每步上界为 0.012，Huber Prior 为非正惩罚。

因此：

- Root Tracking 关闭组的日志正奖励上界沿用原口径。
- Root Tracking 开启组的对应上界需要正确更新。
- 不得将不同 Reward 配置的归一化 Return 直接用于模型优劣排序。

同时保留统一的任务物理指标和原基线 Reward 重新计分结果，便于跨实验比较。

## 15. 新增全身运动质量评价

本轮必须建立比 Foot RMSE 和双肘近限位比例更全面的评价体系。

### 15.1 足步任务

统计：

- 完整四步成功率。
- 首次摆腿成功率。
- 首次落脚成功率。
- 连续落脚数。
- 实际匹配落脚数。
- 全程未提前终止比例。
- Foot Position RMSE。
- Foot Orientation Error。
- 落脚 XY Error。
- 接触状态一致率。
- 支撑脚滑动。

### 15.2 Root 与整体姿态

统计：

- Root XY RMSE。
- Root Z RMSE。
- Root XYZ RMSE。
- Root Heading RMSE。
- Root Roll/Pitch。
- Root 线速度与角速度。
- Root 线加速度。
- 实际身体高度范围。
- Root 相对于支撑足的位置。
- 髋、膝、踝关节与 Reference 的姿态误差。

检查是否存在：

- 身体明显落后或超前于双脚。
- 过度屈膝。
- 异常躯干倾斜。
- 步态左右不协调。
- Root 周期性剧烈摆动。

### 15.3 上半身姿态

分别统计：

- Shoulder Joint RMSE。
- Elbow Joint RMSE。
- Arm Joint RMSE。
- Waist Joint RMSE。
- 每个肩关节的角度误差 RMS/P95/Max。
- 双肘接近机械限位比例。
- 肩部接近机械限位比例。
- 上半身姿态超出容许范围的比例及幅度。

增加身体局部坐标系中的上肢几何评价：

- 左右肘部相对于躯干的位置误差。
- 左右手部相对于躯干的位置误差。
- 左右手部前后摆动幅度。
- 左右手部横向伸展幅度。
- 上臂相对于躯干的方向误差。
- 实际上身运动与 Reference 的相位协调性。

尤其需要识别：

- 手臂横向伸直。
- 长期抬肩。
- 手臂过度向后。
- 肘部极端屈曲。
- 上半身异常僵硬。
- 双臂不合理的非对称运动。

不能仅凭双肘远离机械限位判定上半身动作自然。

### 15.4 运动平滑性

沿用 M4.8/M4.9 的统计方式：

- 上半身实际角速度 RMS。
- 实际角加速度 RMS。
- 实际 Jerk RMS。
- 双臂加速度 P95/P99/Max。
- Raw Action 二阶差分。
- Effective Action 二阶差分。
- 实际 PD Target 二阶差分。
- 双臂 8–25 Hz 高频运动功率。

保留启动阶段 400 Hz 物理子步探针，诊断右肘启动冲击及 Smoothstep 结束后的异常加速度。

对于提前终止试次：

- 分别统计共同有效时间窗口。
- 完整成功轨迹单独统计。
- 不得将短时间运动产生的低误差或低加速度解释为更好的完整运动质量。
