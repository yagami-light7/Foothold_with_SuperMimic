## 4. 新增 Reward 一：Stance Foot Yaw Huber

### 4.1 航向误差定义

跟踪 Reference 中对应足部的航向，而不是 Root Heading。

对于左右脚：

\[
e\_{\psi,i}
=
\left|
\operatorname{wrapToPi}
(\psi_i-\psi_i^{ref})
\right|
\]

优先通过足部 Forward Axis 在地面切平面上的投影计算有符号航向误差。

平地法向：

\[
n=[0,0,1]^T
\]

设实际和参考的单位水平朝向向量分别为 \(u_i,u_i^{ref}\)，则：

\[
\Delta\psi_i=
\operatorname{atan2}
\left(
n^T(u_i^{ref}\times u_i),
(u_i^{ref})^Tu_i
\right)
\]

\[
e\_{\psi,i}=|\Delta\psi_i|
\]

必须核对 Roban 足部局部坐标系的真实 Forward Axis。

避免直接假设足部 Link 的 X 轴就是足尖方向。

正确处理：

- 左右脚局部轴方向。
- Quaternion 顺序。
- ±π 环绕。
- 足部投影接近退化的情况。
- 自动微分稳定性。

这种定义应能够支持未来转弯、转圈等任务。

不要强制双脚始终朝向世界 X 轴，也不要强制双脚始终与 Root Heading 相同。

### 4.2 Dead-zone Huber

\[
d*{\psi,i}=\max(e*{\psi,i}-\delta\_\psi,0)
\]

\[
x*{\psi,i}=\frac{d*{\psi,i}}{\sigma\_\psi}
\]

Huber 函数：

\[
H(x)=
\begin{cases}
\frac12x^2,&x\leq1\\
x-\frac12,&x>1
\end{cases}
\]

最终奖励：

\[
r*{\mathrm{stance,yaw}}
=
-\Delta t\,w*\psi Q*t
\frac{
\sum_i c_i^{ref}H(x*{\psi,i})
}{
\sum_i c_i^{ref}+\epsilon
}
\]

其中：

- \(c_i^{ref}\) 为参考支撑状态。
- \(Q_t\) 为现有 Reference Quality Gate。
- \(\Delta t=0.02\) s。

若没有计划支撑脚，奖励为零。

### 4.3 固定参数

| 参数          |                   数值 |
| ------------- | ---------------------: |
| Reward Weight |                   0.25 |
| Dead-zone     |                     3° |
| Huber Sigma   |                    10° |
| 生效阶段      |       Reference Stance |
| 跟踪对象      | Reference Foot Heading |
| Control dt    |                 0.02 s |

角度在内部统一转换为 rad。

本项使用 Reference Stance Mask，不因机器人实际抬起计划支撑脚而取消方向跟踪。

不要在奖励外层重复乘 Weight、Quality Gate 或 dt。

## 5. 新增 Reward 二：Stance Angular Slip Penalty

### 5.1 基本定义

支撑脚即使足底中心不移动，也可能绕地面法向发生旋转滑动。

因此，需要约束足部在承重期间绕地面法向的角速度。

\[
\omega\_{n,i}
=
n^T\omega_i^{world}
\]

当前固定支撑脚 Reference 的法向角速度原则上为零。

一般形式：

\[
e*{\omega,i}
=
|\omega*{n,i}-\omega\_{n,i}^{ref}|
\]

\[
d*{\omega,i}
=
\max(e*{\omega,i}-\delta\_\omega,0)
\]

\[
x*{\omega,i}
=
\frac{d*{\omega,i}}{\sigma\_\omega}
\]

最终奖励：

\[
r*{\mathrm{angular,slip}}
=
-\Delta t\,w*\omega Q*t
\frac{
\sum_i c_iH(x*{\omega,i})
}{
\sum_i c_i+\epsilon
}
\]

其中 \(c_i\) 表示计划支撑且实际承重的有效 Mask 或连续接触权重。

### 5.2 固定参数

| 参数          |               数值 |
| ------------- | -----------------: |
| Reward Weight |               0.10 |
| Dead-zone     |         0.10 rad/s |
| Huber Sigma   |         0.50 rad/s |
| 约束方向      |           地面法向 |
| 生效阶段      | 计划支撑且实际承重 |
| Control dt    |             0.02 s |

原有 Slip Reward 保持不变。

新增 Angular Slip 主要解决绕地面法向的扭转滑动，不直接惩罚合理的足跟、足尖滚动。

### 5.3 可微足部角速度

优先复用已有可微 RobotKinematics。

如果 WM 已经预测 Root Angular Velocity 和 Joint Velocity，可以通过足部角速度 Jacobian 计算：

\[
\omega*i^{world}
=
\omega*{\mathrm{root}}^{world}

- J\_{\omega,i}^{world}(q)\dot q
  \]

实际公式必须匹配当前浮动基座、Jacobian 和速度坐标约定，避免重复计入 Root Angular Velocity。

如果现有状态定义更适合使用连续两帧足部姿态，则可以采用 SO(3) Log Map：

\[
\omega*i^{world}
\approx
\frac{
\operatorname{Log}
(R*{i,t+1}R\_{i,t}^{T})
}{\Delta t}
\]

需保证时间索引正确，且不能跨 Reset 或 Episode 边界计算。

比较其与真实 Newton Link Angular Velocity 的一致性。

### 5.4 Contact Mask 与 World Model

必须保证真实 Rollout 和 Imagined Rollout 中 Angular Slip 的数学语义一致。

优先复用原 Slip Reward 已有的可微接触代理或可靠的 WM 接触预测。

真实接触力用于独立物理验收。

如果真实 Newton 接触力无法在 WM 中重建，不应在真实和想象奖励中分别使用未经验证的不同 Mask。

如果现有接触预测不可靠，可以使用统一的 Reference Stance 与可微足部接触代理，并明确记录设计及验证结果。

禁止：

- 为逃避滑动惩罚而主动抬起计划支撑脚。
- 跨 Episode 计算角速度。
- 使用不可微 CPU FK 作为 BPTT 主路径。
- 使用 PD Target 代替真实或预测足部状态。
- 静默修改 WM 网络结构。

通过原 Contact Schedule、Stance Position、Swing Clearance 和 Touchdown 等奖励维持接触任务。
