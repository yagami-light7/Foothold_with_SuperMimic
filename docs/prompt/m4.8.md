# M4.8 — Startup Smoothstep & Upper-body Smoothness Ablation

## 1. 实验背景

请先阅读已有的 `m4.3_report.md`、`m4.6_report.md`、`m4.7_report.md` 以及相关代码实现。

M4.7 已经完成：

- 右肘启动冲击根因定位。
- Startup Smoothstep 冻结权重对照实验。
- Upper-body Smoothness Reward 实现。
- 平滑奖励权重离线标定，确定权重为 0.02。
- 37 项回归测试及隔离 CUDA Smoke Test。

M4.7 定义为诊断与预备实验，M4.8 定义为正式训练消融实验。

冻结 Policy 在 0.20 s Startup Smoothstep 下出现步态退化，但这不能证明 Fresh Start 无法适应新的控制方式。

因此，本轮解除冻结 Policy 步态成功率对 Fresh Start 的硬性限制，直接准备正式训练。

保留所有物理安全、训练契约和梯度有效性检查。

## 2. 正式消融实验

| ---------------- | -----------------: | ----------------: | ----------------: |
| M4.3（已有基线） |               关闭 |                 0 |                 0 |

| M4.8-B           |               关闭 |              0.02 |                 0 |

实验目的：

- A：单独验证启动过渡能否降低右肘冲击，并通过重新训练获得稳定步态。

所有组均不使用 Body Prior，验证 Policy 能否自主学习自然、平滑且具有动态平衡能力的上半身动作。

## 4. 复用 M4.7 实现

优先复用 `supermimic/integration/m47_control.py` 及已有奖励和历史状态管理代码，不重复实现。

### Startup Smoothstep

仅针对上半身九个关节：

\[
u_t=\operatorname{clip}(t/T,0,1)
\]

\[
\beta_t=3u_t^2-2u_t^3
\]

\[
q*{\mathrm{cmd},t}
=(1-\beta_t)q*{\mathrm{init}}
+\beta*tq*{\mathrm{hard},t}
\]

其中：

- A/C：T = 0.20 s。
- B：关闭启动过渡。
- 使用真实 Reset Pose。
- 每个环境独立维护 Episode 步龄。
- 第一个控制指令从合法 Reset 姿态开始。
- 第 10 个控制间隔结束后完全恢复 Actor 控制。
- 下肢控制方式不变。
- Reference 时钟正常推进。
- 保留原 Previous Action 和 History 初始化。

### Upper-body Smoothness Reward

\[
r*{\mathrm{smooth},t}
=
-\frac{1}{9}
\sum*{j\in\mathcal J*{\mathrm{upper}}}
(a*{j,t}-2a*{j,t-1}+a*{j,t-2})^2
\]

加权贡献为：

\[
\Delta t\,w*{\mathrm{smooth}}r*{\mathrm{smooth},t}
\]

其中：

- A：w = 0。
- B/C：w = 0.02。
- 使用上半身九个 Raw Action 通道。
- 保留原 Action Rate Reward。
- Episode 头两个指令使用有效历史掩码。
- 不跨 Episode 计算二阶差分。
- 不重复乘以 dt。

不再进行权重搜索，不增加其他 Reward。

## 5. 训练契约与回归检查

确保：

- Newton 实际执行的 PD Target 与 WM 输入的 Effective Action 一致。
- Replay 正确保存 Reset Pose、Episode 步龄及前两步 Raw Action。
- BPTT 起点能够恢复真实历史状态。
- BPTT 与 Newton 使用同一动作变换。
- 想象过程中跨时间梯度正确传播。
- Startup 关闭时恢复 M4.3 原始动作映射。
- Smoothness Weight 为零时恢复 M4.3 原始奖励。
- 两个新增模块均关闭时，当前训练路径与历史 M4.3 等价。

通过固定状态、动作序列和历史权重进行回归测试，尽可能核对 Reward、Observation、Loss 与 Gradient。

如果存在无法消除的历史基线差异，应明确记录，不得宣称严格单变量对照。

## 9. 后续验收目标

训练完成后，将统一使用 CUDA Newton 进行独立评估。

主要目标：

- 整个启动窗口内的右肘加速度峰值降低约 50%。
- 排除启动阶段后的主要平滑性指标尽可能降低约 30%。
- 保持名义完整四步 3/3。
- 扰动完整四步不低于 M4.3 Best 的 4/6。
- 扰动首次落脚和完整存活尽可能保持 6/6。
- 不出现明显的上半身僵硬、异常屈曲或过度伸直。
- 验证不依赖 Body Prior 时，Policy 能否自主学习合理的上半身协调运动。

上述百分比为探索性工程目标，不代表已经取得的实验结果。
