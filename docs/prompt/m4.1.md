## 1. 统一 Action Mapping

将 Roban 的 21 维关节动作统一映射到完整关节活动范围：

\[
a_t=\tanh(\pi(o_t,g_t))\in[-1,1]^{21}
\]

\[
q*{\mathrm{mid},j}=\frac{q*{\min,j}+q\_{\max,j}}{2}
\]

\[
\alpha*j=\frac{q*{\max,j}-q\_{\min,j}}{2}
\]

\[
\boxed{q*{\mathrm{target},j}=q*{\mathrm{mid},j}+\alpha*j a*{t,j}}
\]

要求：

- 从 Roban MJCF/模型配置读取每个关节真实的位置上下限。
- 不使用 `q_default`、F2 初始姿态或动态 `q_ref(t)` 作为动作中心。
- 21 个关节统一采用上述 Mapping，不额外引入动作尺度衰减系数。
- 对缺少有效有限关节限位的情况明确报错，不得随意假设范围。
- 检查 Actor 的 `tanh`、探索噪声、Action Clipping 是否存在重复或冲突。
- 确保训练真实 Rollout、World Model 想象 Rollout、Reward 重算及 Evaluation 使用一致的 Action 语义。
- 保留 PD 力矩限幅和必要的数值安全检查。
- 保持 Action Mapping 与具体 Motion Reference 无关，后续不同步长、步频和转向轨迹共享相同规则。

**不添加站立姿态偏置、不使用 Reference-centered Residual Action。**

## 2. 修正 Asymmetric Actor–Critic

保持现有 SuperMimic Motion Encoder、Shared Decoder、World Model、BPTT 和 Critic 训练范式。

Actor 输入保持不变：

- 10 帧本体历史。
- 未来 10 个时刻的双足目标轨迹。
- Contact / Phase / Root Goal 等现有 Goal 信息。

**Actor 不得直接接收完整关节 Reference。**

Critic 则启用完整全身 Motion Reference：

- 当前完整机器人状态。
- 仿真特权上下文。
- 原有未来 Foot / Root Goal。
- 未来完整 Root Position / Orientation / Velocity。
- 未来 21 维 Joint Position / Velocity。

优先复用已有的 `critic_use_body_reference` 机制，不重复实现已有功能。

此前 Critic 输入为 400 维；根据 M4.0 V2 报告，启用完整 Reference 后预计为 **970 维**。请通过实际代码确认最终维度及时间索引、坐标系和归一化方式。

确保 Critic 的真实状态输入、想象状态输入和完整 Reference 在时间上正确对齐，不发生未来真实状态泄漏。
