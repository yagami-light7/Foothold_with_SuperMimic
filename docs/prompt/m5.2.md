## 4. Root Tilt Tracking Reward

### 4.1 数学定义

目前的 World Upright Reward 为：

\[
U(R)=
\exp\left(
-\frac{1-R\_{zz}}{0.1}
\right)
\]

该项以世界竖直方向为最优目标，而不考虑 Reference 本身的身体倾斜。

由于当前已经存在 Root Heading Tracking，本轮不重复约束 Yaw。

设实际 Root 和 Reference Root 姿态分别为：

\[
R,\quad R^{ref}
\]

分别提取实际与参考的 Heading：

\[
\psi,\quad\psi^{ref}
\]

去除各自的 Yaw：

\[
\bar R=R_z(-\psi)R
\]

\[
\bar R^{ref}=R_z(-\psi^{ref})R^{ref}
\]

令：

\[
e_z=[0,0,1]^T
\]

定义实际和参考的身体向上方向：

\[
u=\bar R e_z
\]

\[
u^{ref}=\bar R^{ref}e_z
\]

Tilt Error：

\[
e\_{\mathrm{tilt}}
=
1-u^Tu^{ref}
\]

等价地：

\[
e\_{\mathrm{tilt}}
=
\frac12\|u-u^{ref}\|^2
\]

推荐采用后一种平方距离实现，避免小误差时的数值消减问题。

Root Tilt Tracking Quality：

\[
Q*{\mathrm{tilt}}
=
\exp\left(
-\frac{e*{\mathrm{tilt}}}
{\sigma\_{\mathrm{tilt}}}
\right)
\]

该项只跟踪参考倾斜，不直接约束完整 SO(3) 旋转，因此不会重复施加纯 Yaw Tracking。

不要直接对 Euler Roll/Pitch/Yaw 分量使用未经处理的角度平方误差作为训练奖励。

### 4.2 参数

| 参数             |                       数值 |
| ---------------- | -------------------------: |
| Root Tilt Weight |                       0.50 |
| Tilt Sigma       |                       0.03 |
| 原 Upright Sigma |                       0.10 |
| Control dt       |                     0.02 s |
| 生效阶段         |                     全周期 |
| Tracking Target  |        Reference Root Tilt |
| Heading Frame    | 实际与参考分别去除自身 Yaw |

0.03 是本轮固定的工程候选值，不是经过权重搜索得到的最优值。

训练前需要利用实际 Reference 倾斜分布和 C1500 轨迹，检查该 Sigma 下的奖励值与梯度规模。

本轮不开展 Sigma 或 Weight 网格搜索。

### 4.3 数值稳定性

必须处理：

- Quaternion 顺序。
- Rotation Matrix 约定。
- Quaternion 归一化。
- Heading 提取。
- Heading 投影接近退化的情况。
- ±π 环绕。
- FP32/TF32 数值误差。
- Reference Quality Mask。
- Episode Boundary。
- BPTT Autograd。

训练奖励不使用 `acos` 作为主要误差计算路径。

Tilt Geodesic Angle 可以用于独立评价。

保持有效参考的时间索引与现有 Root Tracking Reward 一致。

## 5. 三组消融实验

所有实验从完全相同的 M5.1-C1500 初始化。

| Group  | World Upright | Root Tilt Tracking |
| ------ | ------------: | -----------------: |
| M5.2-A |          0.50 |                  0 |
| M5.2-B |          0.50 | 0.50，非正惩罚形式 |
| M5.2-C |             0 | 0.50，正向质量形式 |

### A — Baseline

保留 M5.1-C 完整 Reward，仅继续训练。

\[
r_A=
\Delta t\cdot0.5U
\]

用于判断继续训练本身对 Root 姿态及全身运动的影响。

### B — Add Root Tilt

保留原 Upright，同时增加参考倾斜误差惩罚。

\[
r*B=
\Delta t
\left[
0.5U+
0.5(Q*{\mathrm{tilt}}-1)
\right]
\]

用于验证在保留世界竖直先验的情况下，能否改善参考姿态跟踪。

注意 B 组的 Tilt 项为非正值。

### C — Replace Upright

移除原 World Upright，替换为参考倾斜跟踪。

\[
r*C=
\Delta t\cdot0.5Q*{\mathrm{tilt}}
\]

用于验证消除世界竖直偏好之后，能否得到更加自然的身体倾斜。

三组保持相同的姿态奖励理论上界，不增加总正奖励归一化常数。

但需要注意：B 组同时存在两个可能冲突的姿态目标，其实际可达最大奖励可能低于理论上界；非正惩罚也可能改变生存时长相关的优化激励。

因此不能仅依据三组 Total Return 比较优劣。

如果使用现有 Reference Quality Gate，必须明确其数学语义，在 Real、Replay 和 Imagined Reward 中一致应用，不能在不同路径重复乘 Gate、Weight 或 dt。

所有实验保留原 Survival Reward 和物理终止条件。

C 组移除 Upright 不意味着移除跌倒保护。

## 7. 上半身空间姿态反事实诊断

本轮需要判断手部及肘部空间姿态异常是否主要来自 Root 姿态。

### 7.1 基本运动学关系

对于某一手部或肘部关键点：

\[
p^w=p_b+R_bp^{local}(q)
\]

其世界空间误差可以来自：

- Root Translation Error。
- Root Orientation Error。
- Waist/Shoulder/Elbow Joint Error。

因此不能仅凭手部世界位置偏差判断肘部关节控制不合理。

### 7.2 反事实 FK

使用 C1500 已有轨迹构造以下诊断状态。

| Case | Root Position | Root Orientation | Joint Position |
| ---- | ------------- | ---------------- | -------------- |
| D0   | Policy        | Policy           | Policy         |
| D1   | Policy        | 仅替换 Tilt      | Policy         |
| D2   | Policy        | Reference 全姿态 | Policy         |
| D3   | Reference     | Reference        | Policy         |
| D4   | Reference     | Reference        | Reference      |

D1 中保留 Policy 自身 Yaw，仅使用参考 Roll/Pitch 对应的去航向倾斜：

\[
R*{\mathrm{D1}}
=
R_z(\psi*{\mathrm{policy}})
\bar R^{ref}
\]

保持其余关节状态不变。

分别计算：

- Hand World Position RMSE。
- Hand Root-local Position RMSE。
- Hand Torso-local Position RMSE。
- Hand Orientation RMSE。
- Elbow World Position RMSE。
- Elbow Root-local Position RMSE。
- Elbow Torso-local Position RMSE。
- Upper-arm Direction Error。
- Forearm Direction Error。
- Torso/Chest Tilt Error。

比较 D0→D1→D2→D3 的误差变化。

重点回答：

1. 仅修正 Root Tilt 能改善多少手部空间误差？
2. Root Yaw 是否也是重要误差来源？
3. Root Translation 对手部位置误差贡献有多大？
4. 完整 Root 位姿正确后，手臂局部构型是否仍不合理？
5. 是否存在腰部对 Root 倾斜的反向补偿？

这些是纯运动学反事实诊断，不代表修正后的状态具有动力学可执行性。

不同误差分量存在耦合，不要将各组 RMSE 差值解释为严格独立、可相加的因果贡献。

本轮只进行诊断，不将额外手部或肘部空间误差加入 Reward。

## 17. Reward Freeze 决策

本轮希望成为进入 M6 前最后一次主要的 Reward 调整。

训练完成后，根据以下原则决定是否冻结：

### 情况一：Root 姿态与全身空间姿态明显改善

且保持：

- 完整任务成功率。
- 足部精度。
- 接触稳定性。
- 初态恢复。
- 上半身平滑性。

则选择最均衡模型，冻结 Reward，直接进入 M6 Online RL。

### 情况二：Root Tilt 改善，但手部世界位置仍有偏差

首先使用反事实 FK 判断偏差来自：

- Root Translation。
- Root Heading。
- Waist。
- Shoulder。
- Elbow。

如果剩余偏差较小且动作视觉自然，不继续增加奖励。

不要为了获得更低的运动学误差无限延长平地姿态优化。

### 情况三：Root 改善，但仍存在明显异常手肘构型

只有在以下证据同时成立时，才考虑后续 Elbow Cartesian Position Reward：

1. Root 与 Torso 倾斜已经得到改善。
2. 手部位置跟踪已经较好。
3. 肘部局部空间姿态仍持续异常。
4. 异常并非正常的动态平衡补偿。
5. 现有 Elbow Joint Huber 无法有效限制该异常。

本轮不自动实现任何新增肘部奖励。

### 情况四：Root Tilt 奖励导致明显控制退化

保留 M5.1-C1500。

不要自动开展新的大规模 Reward 搜索。

报告实际失败原因，并评估能否直接进入 M6，通过更丰富的参考数据提高策略能力。
