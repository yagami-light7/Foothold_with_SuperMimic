# M4.2 — SuperMimic Action Mapping 重构与训练准备

## 任务目标

当前 Roban SuperMimic M4.1 使用关节中点 + 半活动范围的 Action Mapping。实验发现 Actor 更新后出现大量动作饱和、力矩饱和及步态学习退化。

现在决定改为**更接近原 SuperMimic 论文的 Action Mapping**，同时保留 M4.1 v2 已完成的 Newton/MJWarp 动力学稳定性修复。

请实际修改仓库代码、完成测试，并准备新的 F2 训练实验。

## 1. 修改 Action Mapping

采用：

\[
\boxed{
q*{\mathrm{target},j}
=
\operatorname{clamp}
(q*{0,j}+\alpha*j a*{t,j},q*{\min,j},q*{\max,j})
}
\]

要求：

- Actor 最后一层采用 `Linear`，输出 21 维连续实数。
- **取消最终 Action 输出的 `tanh`，不再强制限制到 [-1,1]。**
- \(q_0\) 使用 Roban 固定默认站立姿态，与具体 Motion Reference 无关。
- 检查现有 Roban 站立配置是否合理，不直接假设 MJCF 中的全零关节角就是自然站姿。
- \(\alpha_j\) 根据 PD 增益和执行器力矩能力确定，初始参考：

\[
\alpha*j=0.25\frac{\tau*{\max,j}}{K\_{p,j}}
\]

- 上述系数只是初始参考，检查 F2 的关节运动需求和合理动作输出范围后再确定最终配置。
- 最终 PD Position Target 使用 `torch.clamp()` 限制在真实关节上下限。
- 不使用 Reference-centered Residual Action。
- 不引入额外的 Action Target Rate Limiter，除非现有物理修复已经依赖该机制。

检查探索噪声的添加位置，确保不再执行旧的 `tanh` 或 `[-1,1]` 裁剪。

同时检查是否存在重复限幅、重复缩放、关节索引错位或非预期动作饱和。

## 2. 确保训练链路完全一致

重点检查：

- Actor 输出与 Exploration Noise。
- Newton 真实 Rollout 的 Action Mapping。
- World Model 输入的 Action 语义。
- BPTT Imagined Rollout 的 Action Mapping。
- Replay Buffer 存储的 Action。
- Reward / Action Regularization。
- 独立 Evaluation 的动作处理。

必须保证真实仿真和可微想象过程使用一致的动作定义。

`clamp()` 在关节限位外梯度为零，因此需要检查 BPTT 中是否存在严重的梯度截断或大量目标被裁剪。

不允许只修改 Newton 的 PD Target，而忽略 World Model 和 BPTT 的对应逻辑。

## 3. 保留现有网络与物理配置

本次不修改：

- Motion Encoder + Shared Decoder。
- World Model 架构。
- BPTT 训练算法。
- Asymmetric Actor–Critic 架构。
- Actor 输入：10 帧本体历史 + 320 维未来 Foot/Root Goal。
- Critic 输入：970 维完整状态、特权信息与未来 Motion Reference。
- M3.7.1 F2 Reference。
- Reward 主体。
- Newton/MJWarp 的 M4.1 v2 子步、关节限位和 PD 阻尼修复。

尤其注意：**不要为了适配新的 Action Mapping 而回退已经验证有效的 Newton 稳定性配置。**

## 4. 必须完成的测试

### A. Action Mapping 单元测试

验证：

1. Actor 最终输出没有 `tanh`。
2. Actor 能正常输出超过 ±1 的动作。
3. 零动作对应固定 \(q_0\)。
4. Action Scaling 计算正确。
5. 最终 PD Target 不超出机械限位。
6. 21 个关节顺序完全正确。
7. 对不同 Reference 使用同一 Action Mapping。
8. 实际 Rollout 与 Imagined Rollout 的 Mapping 结果一致。

### B. F2 运动范围检查

检查 F2 全段关节参考相对 \(q_0\) 的偏移，计算：

\[
a^{ref}_j(t)=\frac{q^{ref}\_j(t)-q_{0,j}}{\alpha_j}
\]

输出各关节所需动作的最大绝对值、P95 和 RMS。

重点判断新 Mapping 是否具备表达 F2 所需关节运动的能力，以及对应动作幅度是否过大。

不要因为 \(a^{ref}\) 超过 ±1 就认为无法表达，因为新 Actor 不再使用硬 `tanh`。

### C. Newton Smoke Test

使用 M4.1 v2 物理配置，测试：

- 固定零动作。
- 小幅动作。
- 典型 F2 关节目标。
- 随机 Actor 输出。
- 少量环境真实 Rollout。
- WM、Actor、Critic 的 Forward/Backward。

检查：

- NaN/Inf。
- 关节位置异常。
- 关节速度异常。
- PD 力矩饱和。
- Action / PD Target 裁剪比例。
- BPTT 梯度是否正常。

保留现有物理异常监测和安全终止逻辑。
