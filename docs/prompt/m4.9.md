# M4.9 — Long-horizon Training & Soft Upper-body Posture Prior

## 1. 实验背景

请首先阅读：

- `m4.3_report.md`
- `m4.5_report.md`
- `m4.6_report.md`
- `m4.7_report.md`
- `m4.8_report.md`

以及对应的实验配置、Reward、Action Mapping、Replay 和 BPTT 实现。

当前 M4.8 已经完成 Startup Smoothstep 与 Upper-body Smoothness 的双因素消融。

M4.8-C Best（Iter 4500）取得以下结果：

- CUDA 名义完整四步：3/3。
- 组合扰动完整四步：4/6。
- 扰动首次落脚：5/6。
- 扰动全程存活：6/6。
- 扰动 Foot RMSE：31.93 mm。
- 扰动 Root XY RMSE：50.10 mm。
- 扰动力矩饱和率：0.44%。
- 右肘前 0.20 s 加速度峰值降低约 76%–77%。
- 持续段上身加速度 RMS 降低约 34%–44%。
- 持续段 Jerk RMS 明显下降。

但上半身自然性仍存在明显问题：

- 左肘近机械限位比例：93.0%。
- 右肘近机械限位比例：94.7%。
- 左肘长期处于伸直端。
- 右肘长期处于最大屈曲端。
- 左右手前后摆幅分别为 266.7 mm 和 81.3 mm。
- 总体 Action Target Clamp Ratio 约为 26%。

说明仅使用 Footstep Tracking 与 Smoothness Reward，可以改善动作平滑性，但无法保证上半身姿态合理。

另外，多组历史实验在 4000–4500 iterations 才形成完整步态，部分策略在 5000 iterations 时发生性能退化，尚不能判断当前训练预算是否充分。

因此，M4.9 的目标为：

1. 将训练预算从 5000 增加至 10000 iterations。
2. 验证更长时间训练是否能够改善步态学习与收敛稳定性。
3. 重新引入上半身 Motion Prior。
4. 实现带容许区间的 Soft Body Prior。
5. 改善双肘长期贴近机械限位及左右上肢明显不对称的问题。
6. 保留 M4.8 已取得的启动减冲击与持续运动平滑性收益。

本次统一使用 Fresh Start，不进行 Fine-tuning。

M4.9-B 直接复用 M4.5/M4.6 已有的原始 Body Prior。

其未加权形式为：

\[
r*{\mathrm{body}}
=
Q_t\left[
0.7\exp\left(
-\frac{\mathrm{MSE}*{\mathrm{arm}}}{0.5^2}
\right)

- 0.3\exp\left(
  -\frac{\mathrm{MSE}\_{\mathrm{waist}}}{0.5^2}

其中：

沿用已有 dt 缩放方式。

不修改原 Body Prior 的数学定义和数据来源。

## 6. 新增 Soft Body Prior

### 6.1 核心思想

不要求机器人精确模仿每一个时刻的上半身关节角。

允许其在 Reference 姿态附近的一定范围内自由运动，仅在超出合理姿态范围后产生惩罚或奖励损失。

保持上半身主动参与动态平衡的自由度。

本次采用随 Reference 相位变化的 Soft Body Prior，而不是固定站姿约束。

### 6.2 数学定义

关节姿态误差：

\[
e*{j,t}=q*{j,t}-q\_{j,t}^{ref}
\]

定义容许偏差：

\[
d*{j,t}
=
\max(|e*{j,t}|-\delta_j,0)
\]

其中 \(\delta_j\) 是对应关节允许偏离 Reference 的范围。

为保持与原 Body Prior 的可比性，首先采用 Dead-zone Exponential Reward：

\[
r*{\mathrm{soft},t}
=
Q_t
\left[
0.7\exp\left(
-\frac{\operatorname{mean}*{arm}(d\_{j,t}^2)}{0.5^2}
\right)

- 0.3\exp\left(
  -\frac{\operatorname{mean}_{waist}(d_{j,t}^2)}{0.5^2}
  \right)
  \right]
  \]

总奖励：

\[
r_t
=
r_t^{\mathrm{M4.3}}

- \Delta t\,w*{\mathrm{smooth}}r*{\mathrm{smooth},t}
- \Delta t\,w*{\mathrm{soft}}r*{\mathrm{soft},t}
  \]

其中：

- `r_body` 与 `r_soft` 不能同时启用。
- dt 缩放必须与现有 Reward 一致。
- 不重复计算 Quality Gate。
- 不重复乘以配置权重。
- 当所有 \(\delta_j=0\) 时，Soft Body Prior 必须严格退化为原 Body Prior。

### 6.3 容许区间选择

根据真实 F2 Reference 的九关节轨迹及 Roban 机械限位进行逐关节标定。

建议初始候选范围：

| 关节类别 |  容许偏差候选 |
| -------- | ------------: |
| Shoulder | 0.25–0.40 rad |
| Elbow    | 0.25–0.40 rad |
| Waist    | 0.15–0.25 rad |

上述数值仅作为预备标定范围，不是最终固定参数。

重点检查：

- `zarm_l4_joint`
- `zarm_r4_joint`

确保容许区间不能使 M4.8-C 当前的双肘极端姿态获得满额姿态奖励。

尤其需要确认：

- 左肘接近 0.087 rad 的伸直端时是否存在有效奖励损失。
- 右肘接近 −2.269 rad 的屈曲端时是否存在有效奖励损失。
- 合理的屈肘与摆臂是否具有足够自由度。
- Reference 自身是否过于接近机械限位。
- 双侧关节的参数设置是否合理一致。

优先选择简洁、具有物理意义且能够扩展到其他 Reference 的配置，避免针对 F2 某几帧过度调参。

不新增逐关节硬姿态限制，不修改机械关节限位。

## 7. Soft Body Prior 离线标定与梯度诊断

复用 M4.7 Smoothness Calibration 的诊断方法。

优先使用：

- M4.3 Best。
- M4.6 权重 0.02 和 0.05 的代表性 Checkpoint。
- M4.8-B Best。
- M4.8-C Best。

特别使用 M4.8-C 双肘近限位的真实 Newton 状态。

### 7.1 奖励数值标定

检查候选 Soft Prior 权重：

```text
0.01
0.02
0.05
0.10
```

仅进行离线数值与梯度标定，不分别启动完整训练。

统计：

- 原 Body Prior 与 Soft Body Prior 的奖励值。
- 每个关节的超容许区间误差。
- 双肘近机械限位时的奖励损失。
- 加权后每步奖励贡献。
- 相对 Foot Tracking Reward 的比例。
- 相对 Smoothness Reward 的比例。

### 7.2 BPTT 梯度标定

分别计算：

\[
g*{\mathrm{foot}}=\nabla*\theta J\_{\mathrm{foot}}
\]

\[
g*{\mathrm{smooth}}=\nabla*\theta J\_{\mathrm{smooth}}
\]

\[
g*{\mathrm{body}}=\nabla*\theta J\_{\mathrm{body}}
\]

\[
g*{\mathrm{soft}}=\nabla*\theta J\_{\mathrm{soft}}
\]

以及 Critic Bootstrap Gradient。

检查：

- 各项梯度范数。
- Foot 与 Body/Soft Prior 梯度余弦。
- Smoothness 与 Body/Soft Prior 梯度余弦。
- 上、下肢动作通道梯度。
- 左右肘独立动作梯度。
- 初始双支撑、Swing、Touchdown、扰动恢复阶段的梯度差异。

以原 Body Prior=0.02 的梯度强度作为主要标定参照。

优先选择能够对异常肘部姿态提供明确纠正信号，同时不过度压制下肢任务梯度的弱先验。

可将姿态先验相对 Foot Gradient 的约 1%–5% 作为初步工程参考，但不能为了达到该比例而忽略实际纠正方向。

最终只选择一套 \(\delta_j\) 和一个 `w_soft` 用于 M4.9-C。

记录选择依据。

### 7.3 Hard Clamp 梯度专项检查

M4.8-C Best 的双肘长期贴近机械限位，需要检查 Soft Prior 是否真的能够使其离开限位。

区分：

1. 实际关节角的 Reward Gradient。
2. Hard Clamp 前 Raw Action Gradient。
3. Hard Clamp 后 Effective Action Gradient。
4. Actor 参数梯度。

检查：

- Raw Action 是否已经长期超出可执行范围。
- Hard Clamp 是否导致直接动力学梯度为零。
- Soft Prior 是否仍可通过后续 BPTT 状态产生有效梯度。
- 非饱和状态下的纠正方向是否正确。
- 饱和状态下是否存在朝合法区间恢复的优化信号。

使用真实 Newton 有限差分或 matched-state 分支测试复核少量代表性双肘状态。

不能仅凭姿态 Reward 对关节角的解析梯度非零，就断言 Actor 能够摆脱饱和。

如果指数奖励在异常姿态下存在明显梯度衰减，应明确记录，并离线比较 Dead-zone Huber 或二次惩罚作为备选。

只有在原指数方案无法提供合理纠正信号时，才提出备选设计及选择依据。

**本轮不允许直接取消 Hard Clamp，不引入新的 Action Mapping，也不擅自增加第四组正式训练。**

### 13.1 步态与稳定性

以 M4.8-C Best 为主要控制质量基线，并以 M4.3 Best 为步态鲁棒性基线。

| 扰动 Root XY RMSE |    50.10 mm | 尽量保持或降低 |

### 13.2 上半身自然性

重点验证：

- 左肘近限位比例是否由 93% 显著下降。
- 右肘近限位比例是否由 94.7% 显著下降。
- 双肘是否摆脱一侧完全伸直、另一侧完全屈曲的姿态。
- 左右手摆幅是否更加协调。
- Arm/Waist RMSE 是否改善。
- 是否存在长期静止或僵硬的手臂。
- 上半身运动是否保留合理的平衡补偿行为。

将名义双肘近限位比例低于 20% 作为探索性工程目标，不作为理论上的自然姿态标准。

### 13.3 运动平滑性

尽可能保持 M4.8-C 的收益：

- 首步右肘平均加速度：18.3 rad/s²。
- 扰动持续段上身加速度 RMS：36.02 rad/s²。
- 扰动持续段 Jerk RMS：2379 rad/s³。
- 扰动实际 PD Target 二阶差分 RMS：0.0268 rad。

必须同时统计启动结束后的冲击，不能只报告第一个控制周期。

对持续运动同时采用共同有效窗口和成功完整轨迹的全持续段统计，避免提前终止影响平滑性结论。

### 13.4 训练预算有效性

比较各组 5000–10000 轮之间：

- 完整步态成功率变化。
- 上半身姿态变化。
- 平滑性变化。
- Target Clamp Ratio 变化。
- WM 与 Critic 学习状态。
- 后期训练是否仍然发生退化。

不能仅根据第 10000 轮结果判断训练是否收敛，应结合周期评估与多个 Checkpoint 的实际表现。
