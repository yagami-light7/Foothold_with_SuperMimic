# M4.5.1 — Upper-body Motion Prior 鲁棒性诊断与小权重消融

## 一、任务背景与目标

当前项目基于 SuperMimic 的 World Model + BPTT + Asymmetric Actor–Critic，在 Isaac Lab 3.0 + Newton/MJWarp 中训练 Roban 21-DoF 人形机器人跟踪 F2 Foot/Root Goals。

已有实验：

**M4.3 — Swing-Aware Reward**

- 完整四步跟踪成功。
- Foot RMSE 约 0.027 m。
- 使用 Hard Clamp Action Mapping。
- Body Prior Weight = 0。
- 初态扰动后仍具有一定步态鲁棒性。

**M4.5 — Upper-body Motion Prior**

- 基于 M4.3 进行严格单因素修改。
- `body_prior_weight=0.10`。
- Arm Joint RMSE 从约 0.798 rad 降至 0.489 rad。
- Foot RMSE 从约 0.027 m 降至 0.016 m。
- 但统一独立评估的完整四步成功率从 3/3 降至 1/3。
- 初态扰动后的完整四步成功率从 4/6 降至 0/6。
- 受扰动时首次摆腿仍为 6/6，但首次落脚为 0/6。
- M4.5 受扰动后的 6 次评估中有 5 次因为 `root_height` 提前终止。

M4.5 的训练周期评估曾报告 3/3 成功，而最终独立复测只有 1/3，说明还需要检查评估可复现性以及接触事件的临界稳定性。

**本次任务目标：定位 M4.5 步态鲁棒性退化的主要原因，并验证能否在保留上半身改善的同时恢复 M4.3 的步态鲁棒性。**

本轮优先执行诊断，不立即进行全新的 5000-iteration 正式训练。

## 四、任务 B：初态扰动鲁棒性归因

M4.5 的最大问题是扰动条件下的第一次落脚失败和 Root Height Termination。

请先复现历史初态扰动：

- Root XY：各轴 ±0.020 m。
- Root Height：+0.006 至 +0.012 m。
- Roll/Pitch：各 ±1°。
- Yaw：±3°。
- Joint Position：±0.010 rad。
- Root Linear Velocity：各 ±0.020 m/s。
- Root Angular Velocity：各 ±0.050 rad/s。
- Joint Velocity：各 ±0.10 rad/s。

### B1. 分离扰动类型

原实验同时施加多种扰动，不足以判断失败主要由哪一项造成。

本次需要构建单因素扰动实验：

A. 只扰动 Root XY。

B. 只扰动 Root Height。

C. 只扰动 Root Roll/Pitch。

D. 只扰动 Root Yaw。

E. 只扰动 Joint Position。

F. 只扰动 Root Velocity。

G. 只扰动 Joint Velocity。

H. 原始组合扰动。

所有实验从同一 F2 起态开始，采用相同幅度分布和配对随机种子。

M4.3 与 M4.5 必须使用相同的扰动样本。

每类先运行至少 6 个配对样本；对于出现明显退化的类别，再增加样本并执行幅度扫描。

不需要对全部类别无差别使用很大的评估预算。

### B2. 扰动强度扫描

对主要风险扰动进行：

- 0 倍。
- 0.5 倍。
- 1.0 倍。
- 1.5 倍。
- 2.0 倍。

比较 M4.3 与 M4.5 的成功率随扰动幅度变化的情况。

保持物理保护机制，不允许为了扫描强扰动而关闭异常检查。

### B3. 分析前 1.6 s 的控制过程

重点观察：

- 0–0.8 s：初始双足支撑。
- 0.8–1.6 s：首次计划 Swing。
- 1.6 s 附近：首次 Touchdown。

记录：

- Root Height。
- Root Roll/Pitch。
- Root Linear/Angular Velocity。
- CoM 位置与速度。
- 支撑足法向力及接触。
- Swing Foot Clearance。
- Swing Foot XY Error。
- Arm/Waist Joint Position。
- Arm/Waist Action。
- 关节力矩。
- Action Clamp。
- Termination Reason。

如果可以可靠计算支撑多边形及 CoM 投影，请同时记录 CoM 相对支撑区域的裕量；不能简单把静态 CoM 投影当作动态稳定性的完整判据。

### B4. 精确定位首次跌倒机制

对于每个提前终止的样本，定位：

1. 首次明显偏离 M4.3 的物理状态。
2. 首次出现显著 Root Height 下降的时刻。
3. 是否伴随支撑足失去承重。
4. 是否由不合理的躯干或手臂补偿引起。
5. 足部轨迹偏离发生在失衡之前还是之后。

不能仅根据 `root_height` 终止就认定高度控制是根因。

## 五、任务 C：上半身先验是否影响平衡控制？

本任务不预设 Body Prior 一定与 Foot Reward 冲突。

### C1. 上半身补偿能力比较

使用 M4.3 和 M4.5 的匹配轨迹。

分析：

- Arm Joint Position / Velocity。
- Waist Position / Velocity。
- Upper-body Angular Momentum（如果模型状态支持可靠计算）。
- Root Roll/Pitch。
- 支撑脚力矩与反力。
- 躯干姿态恢复速度。
- 初态扰动后的稳定性恢复过程。

重点比较：

**M4.3 是否通过更大的手臂或腰部补偿来保持平衡，而 M4.5 因为上半身跟踪先验减少了这些补偿？**

注意：这种机制需要物理轨迹和受控实验支持，不能仅根据 Arm RMSE 判断。

### C2. 匹配状态下的 Action 对照

从相同真实 Newton 状态出发：

- 使用 M4.3 Actor 产生动作。
- 使用 M4.5 Actor 产生动作。
- 在相同物理模型中分别执行短时 Newton Rollout。

分析：

- 足部跟踪。
- Root Height。
- 支撑接触。
- 上半身动作差异。
- 扰动恢复趋势。

确保两种 Actor 接收的 Observation 与 Goal 完全符合各自训练契约，且没有引入额外 Reference 信息。

### C3. Reward 梯度分解

使用相同真实 Replay 起点分别计算：

\[
g*{\mathrm{foot}}=\nabla*\theta J\_{\mathrm{foot}}
\]

\[
g*{\mathrm{body}}=\nabla*\theta J\_{\mathrm{body}}
\]

以及 Critic Bootstrap 梯度。

统计：

- Foot Gradient Norm。
- Body Prior Gradient Norm。
- Gradient Cosine Similarity。
- Critic Bootstrap Gradient。
- Arm/Waist Action Gradient。
- Lower-body Action Gradient。

按以下状态分组：

- 初始双足支撑。
- 首次摆动。
- 首次落脚。
- 扰动恢复。
- 临近跌倒。

注意，两种 Policy 的参数不同。跨网络不能直接比较参数梯度向量方向；梯度余弦应在同一网络内部计算，跨 Policy 则采用匹配状态下的动作空间局部响应和真实 Newton 效果比较。

重点检查是否在扰动恢复阶段出现明显的 Foot/Body 目标竞争。

- Body Prior 的局部梯度是否准确，而足部相关动力学梯度不准确？
- 是否存在特定扰动状态，WM 认为 Actor 更新有益，但 Newton 实际表现变差？

如果无法建立因果关系，请明确保留这一不确定性。

- `body_prior_weight=0.02`。

其余配置保持一致：

3. Full Clip Survival。

5. Root XY RMSE。

各组都使用真实 Newton 评价。

如果小权重没有稳定改善，不要通过仅挑选少量成功种子宣称有效。

## 十、最终验收标准

本次任务的核心不是继续降低 Arm RMSE，而是判断：

**为什么加入弱上半身先验后，机器人在名义 F2 上更精确，却在轻微初态扰动下显著丧失步态稳定性？**

必须区分：

- 评估复现问题。
- 落脚接触持续时间不足。
- 上半身平衡补偿受限。
- Reward 之间的目标竞争。
- WM 在扰动状态附近的动力学梯度失真。
- 训练分布覆盖不足。

如果多个因素共同作用，请按证据强度给出结论，不能强行归因于单一原因。

只有在短训练和独立 Newton 评估中验证有希望的权重后，才建议进一步进行正式 5000-iteration Fresh Start 实验。

不要自动开始新的完整正式训练。
